Production AI guide

Putting AI agent workflows into production

A plain-language playbook for product, data, and actuarial analysts: let the AI help with review and small controlled changes, while the application keeps the guardrails.

The core idea

In production, the agent should not be treated as a person with unlimited access. It should be treated as a skilled assistant working inside a controlled room, with the host app deciding what it can see, what it can change, and how the result is checked.

Production pattern

Separate the helper from the controls.

An AI agent is useful because it is paired with a host workflow: the AI proposes, the host limits, and the product applies only approved changes.

A

Ask in business language

The analyst asks for an explanation, review, or small edit from the business screen they are already using.

  • Active page context is attached automatically.
  • No manual copy-and-paste of a full DFM file is needed.
H

Host app controls the room

The host application decides the working folder, writable files, sandbox mode, and whether the request is read-only or edit-capable.

  • Review mode is read-only.
  • Edit mode works on a staged JSON copy first.
V

Validate before trust

The output is checked with focused helper commands and basic sanity checks before people rely on it.

  • Use bundled inspection instead of repeated full reads.
  • Run validation after edits, not after every answer.

AI agent technical base

What actually happens behind an AI agent request?

1. Active screen context

The host application packages the active DFM or notebook context so the agent starts with the same business view as the user.

1. Operational risk

Safety means the AI works inside boundaries.

The goal is not to make the agent harmless by asking nicely. The goal is to make harmful actions unavailable.

01

Mode choice

Review is read-only. Edit mode is deliberately narrower.

02

Writable root

The sandbox allows writes only in the current working area.

03

Staged file

The agent edits a local JSON-backed copy before the real file is touched.

04

No free writes

The agent is told not to edit true project paths, install packages, commit, or push.

Plain-language rule

An AI agent should never have more access than the task needs.

  • Give it the active page, not the whole company drive.
  • Let it propose changes, but let the host apply them.
  • Keep a backup and a short manifest for every applied edit.
  • Block requests outside the configured server root.

2. Context and memory

Give the agent enough context, but keep the memory clean.

Good context is not "more text." Good context is the right business facts, the right file copy, and the right conversation history.

2. Context and memory

Build a team knowledge fabric.

A stronger name than long-term memory is the team knowledge fabric: the curated business memory that helps the agent learn how your team works without copying every chat forever.

1. Capture useful signals

Save the parts of human interaction that are reusable: accepted edits, reviewer corrections, common DFM questions, data-quality notes, and business definitions.

More signal, less noise

The memory system should favor examples that were reviewed by people, reused often, or tied to a clear business outcome.

2. Context and memory

Use a context routing map.

The recommended memory indexing pattern is a structured routing map: every memory is stored as a small card with tags, ownership, freshness, and trust level, so the agent can retrieve the right context for the current task.

1. Turn the request into a task fingerprint

Before searching memory, identify what the user is trying to do: review, explain, inspect data, change a setting, or validate an output.

Better than a memory dump

The agent should receive a small context packet, not a pile of old conversations.

Context practice

Use compact business views instead of dumping raw files.

The agent uses DFM helper reads

The helper turns a large method file into focused views: summary, average formulas, ratio triangle, selected rows, and ultimate vector.

For analysts, this means the AI can reason about the method without being distracted by every JSON field.

3. Output quality

Quality comes from fast checks at the right moments.

A production workflow should not test everything after every answer. It should run the smallest useful checks when the agent changes something important.

3. Output quality

Use a tool-first edit pattern.

When an agent edits models, methods, files, or datasets, the safest path is to use proven rule-based skills, macros, and APIs before asking the model to invent a new procedure.

Recommended practice

1
Prefer proven tools

Use existing robust skills, macros, helper APIs, and rule-based methods for file, method, and dataset edits.

2
Build new procedures carefully

If a request needs a new skill or sub-procedure, follow principle-based methods and standard team practice.

3
Retrieve quality data

Use standard APIs and validated sources for model inputs instead of scraping, guessing, or hand-assembling data.

4
Say when confidence is low

If the task is unclear or evidence is weak, inform the user and ask for direction instead of inventing assumptions.

Operating model

Production AI is a managed workflow, not just a chat box.

Business task: explain, review, or adjust
Context package: active page, session, shared rules
Control layer: sandbox, roots, read-only mode
Quality layer: helper reads, validation, backup

Rollout sequence

Start with low-risk review, then add narrow edit workflows only where controls and validation are clear.

Review

Answer questions from active context.

Inspect

Use compact helper views for DFM analysis.

Propose

Draft controlled edits on a staged copy.

Apply

Host applies, validates, backs up, and can revert.

Takeaways

Three habits make agents production-ready.

S

Safety first

Use read-only mode, writable roots, staged files, backups, and host-applied changes.

C

Context discipline

Give the agent the active business view and compact helper outputs, not an uncontrolled file dump.

Q

Quality gates

Run focused checks after edits, keep answers reviewable, and let people approve material judgment calls.
