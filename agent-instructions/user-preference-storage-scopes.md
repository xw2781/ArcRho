# User Preference Storage Scopes

Before adding or moving an app preference, classify it into exactly one of these scopes and use the canonical path builders instead of hardcoding a drive, server root, project folder, or Windows login:

1. **Local-user preference:** Settings that follow only the current Windows user on the current PC belong under `%APPDATA%\ArcRho`. Root files such as `workspace_paths.json` and `local_project_prefs.json`, JSON files under `%APPDATA%\ArcRho\prefs`, and cache-like preferences under `%APPDATA%\ArcRho\cache` are all local-user state. Standalone Arcode uses `%APPDATA%\Arcode` for mode-specific local state, including `user_settings.json`. Browser `localStorage` is also local-user state, but Electron manages its physical profile files; application code should address it by storage key rather than filesystem path. The canonical Python owner for ArcRho/Arcode AppData selection and local preference paths is `frontend/app_server/config.py`; Electron-owned JSON preference paths are built in `frontend/electron/main.js`.
2. **Project-user-specific preference:** Settings that must follow one Windows user within one ArcRho project belong at `<workspace_root>\<projects_dir>\<project>\users\<encoded-windows-login>\preferences.json`. Resolve `workspace_root` and `projects_dir` from the local `workspace_paths.json`, resolve the actual project directory through app-server config helpers, and obtain/encode the login through the shared user-identity and filename-encoding helpers. The canonical path owner is `frontend/app_server/services/project_user_preferences_service.py`; do not construct this path independently in consumers.
3. **Server-shared preference:** Settings shared by all users and projects using the configured ArcRho Server belong under `<workspace_root>\config\<preference-file>.json`. Resolve `<workspace_root>` from `%APPDATA%\ArcRho\workspace_paths.json`; never assume `E:\ArcRho Server`. The current shared dataset number-format preference is `<workspace_root>\config\dataset_number_formats.json`, canonically resolved by `frontend/app_server/config.py::get_dataset_number_formats_path()` and optionally overridden by `ARCRHO_DATASET_NUMBER_FORMATS_PATH`. The shared SQL Server import history is `<workspace_root>\config\mssql_connections.json`, canonically resolved by `frontend/app_server/config.py::get_mssql_connections_path()` with its filename and payload schema owned by `arcrho_api/source_table_contract.py`; it records server/database identifiers and a last-used timestamp only and must never hold credentials. New server-shared preferences must likewise have one canonical filename/path builder in app-server config.

Local-user preferences stay with one PC profile, project-user preferences follow the project and encoded Windows user, and server-shared preferences affect every user of that configured server. Do not use local AppData for a preference that must be shared, and do not use a server-shared file for user-specific state.
