# Frontend: Result Selection

## Purpose
<!-- MANUAL:BEGIN -->
Result Selection is a Project Instance method window for vector output datasets. It combines selected vector sources, and triangle sources through their latest diagonal values, into a row-level weighted selected ultimate vector.
<!-- MANUAL:END -->

## Entry Points
<!-- MANUAL:BEGIN -->
- [`ui/result_selection/result_selection.html`](../../ui/result_selection/result_selection.html) - Result Selection iframe page with Details, Method, Results, Validation, and Notes tabs.
- [`ui/result_selection/result_selection_main.js`](../../ui/result_selection/result_selection_main.js) - Result Selection state, dataset loading, grid calculation, persistence, and dirty-state wiring.
- [`ui/result_selection/result_selection_rpc_bridge_client.js`](../../ui/result_selection/result_selection_rpc_bridge_client.js) - Result Selection sync flow for local JSON versus ResQ JSON.
- [`ui/result_selection/result_selection_rpc_bridge_dialog.js`](../../ui/result_selection/result_selection_rpc_bridge_dialog.js) - Floating Method-tab version comparison dialog.
<!-- MANUAL:END -->

## External Interfaces
<!-- MANUAL:BEGIN -->
- Opens from Project Instance floating windows only in v1. The shell does not expose a standalone Result Selection tab.
- Project Instance creates a new Result Selection from `Add > Result Selection` on a vector dataset row whose Method Type is `None`; existing vector rows with Method Type `Result Selection` open this page for editing directly on the Method tab.
- The page posts generic nested-window dirty state through `arcrho:dataset-dirty`, consumes `arcrho:dataset-save`, and exposes `window.__arcrho_request_close` so Project Instance can ask before closing dirty windows; dirty close requests are handled by an in-page confirm dialog and then confirmed with `arcrho:dataset-close-confirmed`.
- Save writes `methods/RS@<Name>.json` using underscore JSON keys, writes the selected ultimate vector CSV under the reserving-class `datasets/` folder as `<Name>@<OriginLength>.csv`, emits coarser aggregate vector CSVs such as `@6` and `@12` when the active origin length can roll up cleanly, saves a base dataset sidecar with `source_kind: "result_selection"`, `method_type: "Result Selection"`, `status: 0`, `data_format: "Vector"`, and asks the Project Instance host to refresh the cached dataset table.
- The Method tab Sync button uses `/result-selection/rpc-bridge/*` routes to request a ResQ-exported `RS@<Name>.json`, compare it with the local method JSON, and let the user choose the local or ResQ version. Choosing the ResQ version reloads the Result Selection page payload and saves the generated vector CSV and sidecar so outputs stay aligned with the selected Method tab JSON.
<!-- MANUAL:END -->

## Behavior
<!-- MANUAL:BEGIN -->
- Details contains Name, Output Type, an Origin Length selector, and one Ratio Basis pill picker holding up to three datasets. Its contents use the shared Details-page typography: Arial-first, 12px black labels and controls, and a 5px label-to-control gap. Output Type and Ratio Basis use the shared dataset-name picker. Matching the Bornhuetter Ferguson Prior Vector control, the Ratio Basis add button inserts unique 30px-high neutral pills, clicking a pill opens its dataset, right-clicking exposes Delete, and dragging a pill outside the picker removes it. The Method-tab active Ratio Basis selector stays synchronized with the same list and remains the calculation selector. The Origin Length selector starts from `12`, `6`, `3`, and `1`, then filters out values that are more detailed than any included non-engine source dataset can support; for example, an annual input source allows only `12`, while quarterly-or-finer non-engine sources allow `12`, `6`, and `3`. Engine-generated sources (`source_kind: "engine"`) do not impose this floor because the editor can request a matching length-scoped cache from the data engine.
- Method is the main working tab. It displays one source-value column and one editable Weight column for each selected source dataset. Source columns are ordered into Triangle and Vector groups, followed by the Selected Ultimate and calculated-statistics columns, with narrow blank separator columns between adjacent groups and a single connected header row. `Show Weights As` hides or shows Weight columns without changing the stored weights or calculation. A Weight display dropdown next to `Show Weights As` switches visible Weight cells between editable Index weights and read-only effective row percentage weights.
- The Method toolbar is grouped into compact, content-sized Formatting, Statistics, and active Ratio Basis sections, while the ResQ Sync command sits on the right side of the Result Selection tab bar. Formatting contains Show Weights As and its weight-display dropdown. Statistics contains Show Ratios as Percentages and the Decimal stepper. The Ratio Basis selector switches among the datasets defined on Details and immediately changes the basis vector used for ratio statistic calculations. The ResQ Sync command opens a draggable comparison dialog showing each version's local `M/D/YYYY HH:mm:ss` timestamp, Details summary, Method source count, selected positive-weight count, source selected counts, selected ultimate preview, and notes preview without exposing local or temporary JSON file paths. If the ResQ temp file is a bridge status/error JSON instead of a Result Selection method payload, the ResQ card shows that message and disables applying that version.
- Inactive Result Selection tabs use the same pale hover fill as Bornhuetter Ferguson tabs, while active-tab fill and weight remain unchanged.
- Method Weight edits synchronize source-cell calculation selection: entering `0` clears the paired source-value cell selection, and entering a positive weight selects it. Double-clicking a selected source-value cell clears its paired Weight to `0`; double-clicking an unselected source-value cell sets its paired Weight to `1`. Weight cells use grid-cell selection rather than a text-caret cursor; double-clicking a Weight cell toggles `0` to `1` and any non-zero weight to `0`. Editable Weight cells display one decimal place, with non-zero values blue and zero values muted gray. Highlighted source-value cells or Weight cell ranges accept typed numeric values, applying the typed value to the paired Weight cells. Pasting a tab/newline range into a Weight cell applies values across visible Weight columns and rows with the same selection sync.
- Method row labels use the same ArcRho origin-header lookup as the Dataset Data tab, keyed by the Details tab Origin Length; the grid uses DFM Ratios-style table font, fixed row, and cell sizing. Statistic columns other than Selected Ultimate use the normal unfilled table background.
- When opening an existing Result Selection method, stored `method_tab.origin_labels` from the method JSON take precedence over sidecar or project fallback labels so migrated methods render their saved accident-year labels on first open.
- Method row count follows the loaded origin labels for the selected Origin Length, so longer source vectors do not expand the Method grid beyond the selected annual, half-year, quarterly, or monthly header set.
- Method grid columns can be resized by dragging the right edge of each header; only the dragged column changes width while the total table width follows the column sum. Weight columns stay narrower than source-value columns but keep a minimum width that preserves the `Weight` header label, and column labels wrap to at most three lines before truncating. Source dataset headers use a right-click menu with `View/Edit`, `Add`, and `Delete` actions instead of inline delete buttons.
- Method source-value cells have two interaction states: double-click toggles the paired Weight between `0` and `1`, making positive Weight cells selected for `Selected Ultimate`, while single-click/drag creates a temporary highlight range across any Method grid columns. The Method grid opens without a temporary highlight; clicking an already highlighted cell keeps it highlighted, clicking an origin-label cell sets that full row as the temporary highlight without toggling it off, clicking any non-separator column header sets that full column as the temporary highlight, Ctrl/Cmd-click adds or removes individual cell/row/column highlights, Shift-click extends the active highlight to the clicked cell/row/column, and the Method cell context menu includes `Remove Highlights` to clear the current temporary highlight. The Total row is selectable and copyable, uses bold text in every Method grid cell, but remains read-only for typed Weight or Selected Ultimate edits. Typing numbers while a highlight range is active builds one batch value; if any highlighted source-value or Weight cells can be edited, the value applies only to those paired Weight cells, otherwise a highlight containing Selected Ultimate cells writes the same custom ultimate value to each highlighted Selected Ultimate row. Arrow keys move the active Method highlight one cell at a time, keep the highlighted row fully visible below the sticky header, skip blank separator columns for single-cell highlights, and prevent Up/Down from scrolling the Method page while a highlight is active. Pressing `Esc` clears the current Method highlight. The Method cell context menu and `Ctrl+V`/`Cmd+V` can paste clipboard values into the active editable highlight using the same Weight-before-Selected-Ultimate targeting rule, and Excel-style ranges extend down and right from a single selected cell. Selecting a new range resets the typing session so the next number overwrites instead of appending. Highlighted selected source cells use stronger green, highlighted Weight cells use cyan, Selected Ultimate cells keep their yellow fill in both normal and highlighted states, custom Selected Ultimate overrides use red text, and non-selected highlighted cells use blue; only the initial cell in a highlighted range shows the dashed border. Origin labels and dataset headers use normal weight at rest and become bold when their related row or column is highlighted. Right-clicking a highlighted range or pressing `Ctrl+C`/`Cmd+C` copies tab-delimited visible values for Excel paste. Right-clicking a highlight that includes Selected Ultimate cells can revert custom values for the highlighted ultimate rows or revert all custom Selected Ultimate values in the column.
- Default sources are DFM output vectors from the same project, reserving-class path, and Category as the output vector. DFM input triangles and intermediate triangle records are not added by default.
- Users can manually add vector or triangle datasets from the same reserving-class path through the shared dataset-name picker. Added source datasets must have the same Category as the Result Selection output vector; changing the Output Type to another Category removes mismatched loaded source columns. Added source columns are inserted in alphabetic dataset-name order instead of always going to the far right. Vector sources use their first CSV column; triangle sources use each row's latest available numeric diagonal value. Empty source cells display as muted gray `0` values in the Method grid while remaining unavailable for source selection and calculations. When an engine-generated source's native stored length differs from the Result Selection Origin Length, the editor materializes a cache at the Result Selection length and reads that length-scoped CSV without changing the source sidecar or native cache.
- When a source Dataset, DFM, or Result Selection window in the same Project Instance has unsaved edits, Result Selection can consume its `arcrho:dependency-source-preview` values in-memory without marking the dependent method dirty or writing disk JSON. When the source saves, cancels, or closes without saving, Result Selection receives `arcrho:dependency-source-cleared`, drops the temporary source values, and reloads that source from the persisted cache/method output.
- The Method tab keeps its toolbar fixed at the top of the tab panel and scrolls the grid body horizontally and vertically inside the grid frame. Its table scrollbars use the same quiet framed tray, compact arrow buttons, and scroll-aware thumb emphasis as the Dataset Data tab.
- `Selected Ultimate` is calculated per row as `sum(source_value * weight) / sum(weight)` over numeric source values with positive weights. If no positive weighted source values exist for a row, the selected ultimate is blank. A custom Selected Ultimate value overrides the calculated value for that row until reverted, and saved output uses the displayed custom-or-calculated value. When the Method grid includes at least one triangle source, it also shows a `Reserve` statistic column after Selected Ultimate; Reserve is `Selected Ultimate - latest developed`, where latest developed is the first triangle source's displayed latest-diagonal value for the row.
- When an active Ratio Basis is selected, the statistic section includes an `Ultimate / Basis` ratio column. The column is labeled `Frequency` when the Result Selection output Category contains `count` and the active Ratio Basis dataset name contains `exposure`. The ratio is `Selected Ultimate / active Ratio Basis` and respects the percentage and decimal settings. The active ratio-basis dataset must load at the active Result Selection Origin Length; length-scoped caches are used when available, engine-generated basis datasets are materialized at the Result Selection length when needed, and mismatched basis lengths are rejected instead of rendering a partial statistic column.
- The Results tab shows origin labels, loaded triangle latest-diagonal columns, Selected Ultimate, Reserve when available, and the active ratio statistic column when an active Ratio Basis is selected. Results cells support the same click, drag, row-label, and header-label highlighting behavior as the Method grid, but remain read-only.
- Saving Result Selection stores each Method tab source dataset's `source_kind` in the method JSON, stores the Method tab origin labels in the output vector sidecar as `origin_labels`, records the Method tab source dataset names as a plain string array in `Precedents`, adds the output dataset to each source sidecar's `Dependents`, and clears the output review `status` to `0` alongside the generated native-period vector CSV. Quarterly and half-year Result Selection outputs also save coarser aggregate CSVs grouped by half-year/year in the same `datasets/` folder.
- Cancel closes the Result Selection window; when dirty, it first shows one small draggable in-page confirmation dialog before discarding changes, avoiding stacked browser or shell confirmation windows.
- The Validation tab is present for v1 but intentionally renders a placeholder.
- Notes reuses the shared notes editor interactions for formatting, path highlighting, indentation, and dirty-state behavior while saving notes inside the Result Selection method JSON.
- Right-clicking a Result Selection page tab temporarily moves that live tab page into a draggable, resizable floating window inside the Result Selection page, using the same shared tab pop-out behavior as DFM and Dataset. The floated tab keeps its original controls, event handlers, dirty-state behavior, grid state, and notes state because the actual tab DOM is moved rather than cloned. Closing the floating window, right-clicking its titlebar, or right-clicking the grey popped tab button docks the tab back into the normal tab area.
<!-- MANUAL:END -->

## Data/State/Caches
<!-- MANUAL:BEGIN -->
- Result Selection loads cached dataset values through the app-server `/dataset/cache/load` endpoint so filesystem access remains server-side. For engine-generated sources, it can call `/arcrho/tri` or `/arcrho/vec` with `WriteSidecar: false` to create only the needed length-scoped cache, then load the exact generated CSV by filename or requested length.
- The method JSON format marker is `arcrho-result-selection-method-by-tab-v1`; keys use underscores, for example `details_tab`, `method_tab`, `loaded_datasets`, `ratio_basis_datasets`, `active_ratio_basis_dataset`, `calculated_ultimate`, `selected_ultimate`, and `method_metadata`. `details_tab.ratio_basis_datasets` stores up to three configured ratio-basis dataset names, and `details_tab.active_ratio_basis_dataset` stores the basis currently used by the Method ratio statistic column. Ratio-basis values are recalculated from the selected dataset and are not persisted in the method JSON. `method_tab.loaded_datasets[*].values` stores one value per origin row for each loaded source dataset; vector sources use vector values, and triangle sources are transformed from the latest available diagonal values before save. `method_tab.calculated_ultimate` stores the derived weighted vector before user overrides, `method_tab.ultimate_overrides` stores only explicit user-entered override values, and `method_tab.selected_ultimate` stores the final vector shown in the Method tab's Selected Ultimate column. Persisted numeric method arrays are rounded to at most six decimal places. Method source selection is derived from `method_tab.loaded_datasets[*].weights`, where `0` means not selected and a positive value means selected; no separate `selected` array or `value_source` field is stored.
- Project Instance's cached dataset index recognizes saved Result Selection method JSON files and reports their output vector rows with Method Type `Result Selection`.
<!-- MANUAL:END -->
