Tab Type Icon Preview

The glyphs that sit at the left edge of every tab in the main tab bar. The artwork and the type-to-icon mapping live in ui/shell/tab-type-icons/; this page only renders them.

In The Tab Bar

Real metrics: a 14px icon, 6px of air before the label, 28px tab height.

States

One monochrome file per type. The icon takes the tab's own text color and only changes opacity between resting and active, so every theme is covered without a second drawing.

Every Icon

Shown at 14px as the tab bar draws it, then at 20px and 34px so the drawing can be checked. A type with no icon of its own falls back to the generic page glyph.
