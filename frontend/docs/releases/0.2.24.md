# Release 0.2.24

Released on 2026-06-10.

## User-Facing Changes

### Features
- **dataset**: Added eager recalculation for app-calculated datasets when their cached component datasets are saved or refreshed.
  - Calculated non-generated outputs stay in the selected reserving-class datasets folder with read-only sidecars.
  - Dataset Viewer now treats calculated sidecars as read-only.
- **dataset**: Project Instance can add generated datasets through the data engine and create editable empty caches for non-generated datasets.
  - The Add Dataset picker now shows the Generated flag from project dataset types.
  - Editable datasets support pasting tab-separated values from Excel while generated datasets open read-only.
- **project instance**: Added a Help menu action to reveal the selected reserving-class path folder in File Explorer.
- **project instance**: Project Instance now lets users click individual toolbar path levels to switch that level from a compact popup list.

### Improvements
- **project settings**: Project names and virtual folders now use a single project index while source table paths stay with each project field mapping.
  - The project registry uses projects/index.json instead of separate project map and folder structure files.
  - Data-engine source CSV lookup now reads table_path from the project's field_mapping.json.
- **shell**: Clear Cache & Reload now restores the current shell page after clearing Electron cache and storage.
- **dataset**: Updated Project Instance cached dataset rows so custom instance Names are counted separately from their Dataset Type names.
- **dataset**: Shortened reserving-class index.json folder signatures to a sha256 digest instead of storing the full physical file signature text.
- **dataset**: Store reserving-class dataset CSV caches, method JSON files, sidecars, and index.json in a clean data folder layout.
- **project instance**: Adding a dataset from Project Instance now selects and highlights the new row instead of opening it in a floating window.
- **dataset**: Improved the Project Instance Add Dataset picker so it scrolls cleanly and can be dragged or resized.
- **dataset**: Project Instance now refreshes the dataset table automatically when cached dataset instances are added or removed on disk.
- **dataset**: Made Project Instance context-menu submenus easier to reach without disappearing.
- **dataset**: Allowed adding a dataset from the project-instance empty cached-dataset area.
- **reserving class picker**: Added Copy Path as the first action in reserving-class favorite path context menus.
- **reserving class picker**: Reserving-class path pickers now always select final paths with a single click and no longer show the double-click selection preference.

### Fixes
- **dataset**: Fixed duplicate dataset instance name warnings when adding datasets from Project Instance.
- **dfm**: Fixed direct-open DFM method loads so saved ratio selections are retried after restoring Details inputs and refreshing the embedded dataset model.
- **dataset**: Fixed the Add Dataset picker header so scrolled table contents no longer show through the top seam.
- **dataset**: Fixed Project Instance empty non-generated triangle caches so their editable zero cells follow the project's latest diagonal orientation.
- **dataset**: Stored Project Instance non-generated placeholder datasets in the selected reserving-class datasets folder with editable input sidecars.
- **dataset**: Fixed Project Instance dataset table sorting so Last Modified and Created use actual timestamps instead of formatted date text.
- **project instance**: Project Instance toolbar path popups now stay open while users scroll within their option list.

## Internal Notes

- **arcbot**: Moved ArcBot Electron IPC, request state, assistant host helpers, and lifecycle cleanup out of electron/main.js into a dedicated arcbot_host module.
- **shell**: Added a Help menu shortcut for toggling the desktop developer panel.
