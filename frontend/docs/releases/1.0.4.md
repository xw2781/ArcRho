# Release 1.0.4

Released on 2026-06-15.

## User-Facing Changes

### Features
- **arcode**: Moved scripting into the canonical Arcode workspace and added standalone Arcode installer support.
  - ArcRho scripting launch actions now open Arcode instead of the legacy Scripting Console page.
  - Standalone Arcode builds use a separate slim scripting backend and Arcode installer identity.
- **project instance**: Project Instance DFM vector rows now offer Show as vector in the row context menu.

### Improvements
- **scripting**: Removed the seeded Apply Growth Adjustments macro fallback from the Macro window.
- **ai assistant**: Consolidated the ArcBot assistant widget so ArcRho and Arcode share the same panel, styling, and behavior.
  - ArcRho keeps its DFM approval behavior while Arcode keeps its notebook-focused assistant context.
- **shell**: Made active shell tabs visually connect to the workspace body without resolution-sensitive offsets.
  - Inactive tabs keep a single clean bottom border.
  - Dragged tabs stay aligned with the tab strip without the extra dock-target border or topbar height jump appearing during reorder.

### Fixes
- **ai assistant**: Restored ArcBot App Context tooltip details for DFM windows opened inside project instances.
- **dataset**: Dataset tabs now stay dirty after Data-tab setting changes and can save those changes from the File menu or Ctrl+S.
  - Saved Data-tab settings also restore the transposed view state.
- **dfm**: DFM Details now selects Output Vector from project vector dataset types and Input Triangle from cached triangle instances.
- **project instance**: Project Instance Add > DFM now opens a fresh DFM Details window for the selected dataset.
