# Release 0.2.21

Released on 2026-06-05.

## User-Facing Changes

### Improvements
- **shell**: Added a Check for Updates button to the ArcRho About dialog.
- **dataset**: Kept ArcRhoTri metadata in one base dataset JSON sidecar while retaining mode-specific CSV caches.
- **dataset**: Added Dataset Save and Cancel controls for saved period lengths and notes.
  - Dataset pages now reload saved Origin Length and Development Length from the generated sidecar JSON.
  - The Data tab reserves a table-width row below the grid for Save and Cancel so large tables remain scrollable and the buttons stay connected to the bottom edge.
  - When there are no unsaved changes, Save uses the same neutral style as Cancel.
  - Closing or canceling with unsaved period length or notes changes now uses a Dataset confirmation box where Yes discards changes and Cancel returns to the page.
- **dfm**: Added a DFM Save and Cancel row for method changes.
  - Save uses the existing DFM method save flow.
  - Cancel confirms before restoring the last loaded or saved DFM method state.
- **project instance**: Project Instance now highlights the active nested window and shortens matching Dataset and DFM window titles.
- **project instance**: Project Instance dataset-table group collapse and expand actions now apply to headers at the clicked grouping level.
- **project instance**: Removed the visible resize grip from Dataset and DFM floating windows while keeping resize behavior available.

### Fixes
- **project instance**: Kept the Project Instance dataset index focused on logical cached dataset entries instead of physical CSV variants.
  - Length and mode-specific cached CSV files now collapse to their base dataset name in dataset_instance_index.json.
- **dataset**: Made the Dataset Data tab Transposed checkbox update the grid, chart, and copied selections.

### Breaking Changes
- **project instance**: Project Instance and DFM now use dataset_instance_index.json instead of method_index.json for selected-path dataset metadata.
  - The new index stores cached dataset names, file metadata, folder signatures, and DFM method types for the Project Instance dataset table.
  - Existing method_index.json files are not read as fallback caches.
