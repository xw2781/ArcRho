# Release 1.7.2

Released on 2026-09-20.

## User-Facing Changes

### Improvements
- **project instance**: The dataset table's Status column now also turns yellow when a linked Excel workbook holds different numbers, so a link that needs refreshing is visible without opening Manage Excel Links.
  - The check runs on its own for the selected reserving class: the linked cells are read on Arco Server when the class opens, after a save in it, and whenever a workbook is saved outside ArcRho, which a 15-second file check notices.
  - Hovering the Status cell says which of the two reasons applies - an input dependency or an Excel workbook - and names the workbook and how many linked values differ.
  - Nothing is stored by the check: marking a row for review still reflects only the stored flag.
  - A class with no Excel links is not re-scanned on the timer, and a class whose Excel Link Manager is open is read once for both, not twice.
- **dfm**: A DFM window shows unsaved changes only when an edit really changed something, and no longer asks to discard changes that were undone.
  - After each edit the window compares its values, selections, and notes with the last loaded or saved state; the unsaved-changes marker shows only when they differ, so a click that changes nothing never shows it.
  - When later edits bring the window back to its saved state, the marker clears, Save is disabled again, and closing asks nothing.
  - Opening or refreshing a method still never marks it as edited.
- **project instance**: Manage Excel Links now tells you whether a linked value actually changed, keeps itself up to date, and can load the changed values for you.
  - Status compares the real cell values against the workbook instead of only comparing file times, so a workbook saved without edits no longer reads as out of date.
  - Refresh all shows which datasets and methods hold changed values, and after you accept, loads and saves exactly those and recalculates what depends on them.
  - When the recalculation finishes, a short notice lists the downstream objects whose values really changed, each one a link that opens it.
  - The list refreshes itself every few seconds and after any save in the class, so the manual refresh button is gone.
  - Rows now select like the dataset table, and the right-click menu, including the new Refresh links, acts on every highlighted row.
  - The right-click menu now depends on the column: the first three columns offer the dataset's actions (open it, copy its name) and the workbook columns offer the file's (open it, open its file location, copy its path, change the link).
  - Break link removes an object's link to a workbook and keeps the numbers it already holds, after a confirmation that lists what will be broken.
- **dataset**: Opening a Dataset or a DFM method now asks whether the linked Excel values really changed instead of whether the workbook file is newer, and the window opens without waiting for the answer.
  - A workbook saved with no change to a linked cell no longer raises a prompt; the prompt appears only when a linked cell now holds a different number, and it names the workbooks and how many stored values they no longer match.
  - When every linked value still matches, the status bar reads 'Linked values are refreshed, dataset is up to date.' ('method is up to date.' on a DFM).
  - The stored data is shown first and the workbooks are read afterwards, so a slow workbook no longer delays the window.
  - Linked workbooks are opened on Arco Server whenever it can be reached, the same machine the Excel Link Manager and a link refresh already use, and only over this PC's own drive when it cannot.
- **dataset**: A Dataset window and a DFM Ratios tab now open with a cell already selected, so the formula bar shows a formula or a value instead of asking you to pick a cell.
  - A Dataset window opens on the first cell holding a formula, read across each row in turn; a table with no formula opens on its first cell.
  - A Ratios tab opens on the green selected average of the first column, showing its formula when that row is User Entry and its value otherwise.
  - Once you move or clear the selection yourself, the window leaves it where you put it.
- **shell**: Renamed the Home My Workspace card and tab to File Browser, so it no longer shares a name with Arco Workspace.
  - The Home card, the tab title, the Browsing History filter, and the browsing-history-folders label all read File Browser now; the underlying tab type and folder history are unchanged.
- **build**: Installing an update is now one click, and setup can no longer be blocked by a process the app left behind.
  - Update now hides the main window at once and shows the download in a small progress window of its own, so a frozen main window never appears.
  - The app closes its background server completely and confirms it is gone before setup starts; the ordinary quit path waits for the same cleanup.
  - Setup started from the app skips its option, location and finish pages, shows only the file progress, and relaunches the app when it is done.
  - Setup closes every process running from the installation folder, not only the main window, and names any process it could not end.
- **dfm**: Reference names in a Ratios formula are now written in colour while you type them, matching the fills on the rows they name.
  - Each reference keeps one colour across the formula bar and the table, so a formula and its sources can be read against each other while it is being edited.
  - Selecting the text keeps the colours readable, and Dark mode uses a lighter shade of the same colours.
- **dfm**: The Ratios summary table now colours a User Entry formula's source cells only while that formula is being edited in the formula bar.
  - Selecting or highlighting a User Entry cell no longer fills the rows its formula names, so the table keeps its ordinary colours until you start editing.
  - The colours clear as soon as the edit ends, whether it is committed, cancelled, or abandoned by clicking away.

### Fixes
- **dataset**: A calculated formula that reads an Engine-generated dataset at another period now rebuilds it at the formula's own period instead of failing to refresh.
  - Saving a quarterly vector such as an expected loss ratio failed its dependent 'Expected Net Loss % * Earned Premium' with 'operands could not be broadcast together with shapes (40,1) (10,1)', because the Earned Premium was read from its annual file.
  - The refresh now asks the Engine for the generated dataset at the formula's period, the same way a method reads a generated precedent.
- **dataset**: A generated dataset reopens at the display lengths you saved instead of falling back to the lengths it was first built at.
  - Saving a new origin or development length on an Engine-generated dataset already wrote the choice; opening the dataset from Project Instance then showed the old lengths again.
  - The open now rebuilds the dataset at the saved display when its file is at another shape, the same way a method reads a generated precedent at its own period.
- **dfm**: A Ratios cell that is not User Entry now reads as an equation in the formula bar, and its value can be selected and copied.
  - The bar shows the row name, an equals sign, and the cell's unrounded value.
  - Text in the formula bar can be selected with the mouse and copied, which the page-wide selection lock previously prevented.
- **dfm**: The Ratios formula bar now keeps its place in the window when the tables are scrolled sideways.
  - The bar takes the width of the visible area instead of the full table width, so the row label and the workbook button no longer sit off screen on a wide window with a long table.
  - Dragging to select part of a formula no longer scrolls the tables sideways.
- **excel add-in**: Excel add-in 3.0.1 loads missing values after formula entry and fixes slow workbook refresh discovery.
  - Typing, editing, or pasting an ArcRho formula loads missing results without requiring a Refresh button, including formulas with an explicit project name.
  - Opening saved workbooks and ordinary recalculation continue to use saved values without contacting the server.
  - Refresh Workbook scans large array formulas once and shows progress while finding formulas.
- **excel add-in**: Excel reads generated datasets at any period: coarser ones roll up from the published values, finer ones or another mode are calculated by the Engine without changing the publication.
  - Generated triangles and vectors roll up from their published CSV using its native period lengths.
  - A generated dataset asked for at a finer period, a non-multiple, or another cumulative/calendar mode than its publication, such as ArcRhoVec at 3 months for an annually published exposure vector, is calculated by the ArcRho Engine from the source table and cached beside the publication.
  - Excel leaves the published CSV, sidecar, and reserving-class index unchanged.
  - A refused shape now names the published and requested periods in its message.

### Breaking Changes
- **app**: The app is now called Arco Workspace, and the Excel worksheet functions are renamed from the ArcRho prefix to Arco.
  - The installer, the desktop shortcut, the window title, the splash screen, the About box and the user manual all carry the new name; the shortcut on your desktop reads Arco.
  - Excel worksheet functions are renamed: ArcoTri, ArcoTriDiag, ArcoTriCell, ArcoTriOrigin, ArcoHeaders, ArcoVec, ArcoVecCell, ArcoProjectSettings, ArcoReservingClasses and ArcoNodeContents.
  - The old ArcRho function names no longer work, and neither do the older ADAS names; a formula that still uses one returns #NAME? and has to be rewritten with the Arco name.
  - In-cell dataset formulas in the app follow the same names, so a saved cell link written with an ArcRho name has to be entered again.
  - The Excel add-in reads the default project name from a sheet called either Arco Settings or ResQ Settings, and Connect and Login creates the Arco Settings sheet on a workbook that has neither.

## Internal Notes

- **build**: Release Manager can publish a successful build straight away, and a short window no longer hides its panels.
  - Publish after build is on by default, so one confirmation covers the build and the GitHub Release that follows it; the publication is skipped when the build fails.
  - A window too short for every panel now scrolls instead of squashing the build panel under the one below it.
