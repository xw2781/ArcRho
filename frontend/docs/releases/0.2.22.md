# Release 0.2.22

Released on 2026-06-05.

## User-Facing Changes

### Features
- **project instance**: Project Instance dataset rows now support persistent multi-selection, row actions, and confirmed cached-file deletion.
  - The app status bar shows the selected dataset count when more than one row is selected.

### Improvements
- **shell**: Added a lightweight Check for Updates action to the ArcRho About dialog with clearer unavailable-location and missing-checksum feedback.
- **build**: Moved the installer update feed to the releases installer folder and publish release builds there automatically.
- **project instance**: Removed dataset-table row hover fill and browser tooltips from Project Instance.
