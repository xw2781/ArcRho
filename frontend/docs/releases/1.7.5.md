# Release 1.7.5

Released on 2026-09-23.

## User-Facing Changes

### Features
- **project instance**: The dependency graph can now filter by status, category, and method type, showing matching datasets and their surrounding chain.
  - Status, Category, and Method Type filters replace the old graph toolbar cue.
  - Show matched items only narrows the graph to matches; unchecking it adds their upstream and downstream context.
  - Filter and Show matched items only choices are remembered per Windows user and restored the next time a graph opens.
- **dfm**: A DFM can copy every setting from another DFM with Load Settings From Another Method on the Details tab.
  - Pick a reserving class and one of its DFMs; the lengths, decimal places, average rows, selections, matching exclusions and Curves choices are copied.
  - The name, output type, input triangle and Notes stay, the copy stays unsaved until Save, and Undo steps back over it.
- **excel add-in**: Reset Add-in References updates add-in paths and supported function names using a simple Arco or 64-bit ResQ target selector.
  - Arco is always the default. ResQ is disabled with an explanation on PCs other than NE7SASWPN02, and conversion is rejected there.
  - Old 32-bit ResQ paths are recognized. Choose Update workbook to apply the selected target without a preview step.
  - The existing progress window reports each sheet, cells checked, and update progress, with cancellation for large workbooks.
  - Legacy arrays and dynamic spills retain their shape; protected content and formulas Excel cannot update are reported.
  - The workbook recalculates after repair. Refresh if data is missing, then save to retain the changes.

### Fixes
- **arcbot**: ArcBot replies no longer show stray backslashes and HTML codes in place of ordinary punctuation.
  - SQL Format Validation review findings read as plain sentences, so hyphens, underscores, periods, and comparison operators appear as written.
  - Escaped text still cannot turn itself into headings, bold, code, or links in the chat.
- **bornhuetter ferguson**: A Bornhuetter Ferguson origin with no Latest value yet, such as a quarter beyond the current quarter, now takes its Selected Prior as New Ultimate instead of showing null.
  - A quarterly method therefore produces an estimate for the full year.
  - Saved methods keep their old column until recalculated; tools/restate_bf_unobserved_origin_ultimates.py republishes a whole project and walks its dependents.
- **dfm**: A new DFM's Decimal Places now starts at 4 instead of taking the input triangle's precision, so ratios on a claim-count triangle no longer show as whole numbers.
  - Existing DFMs keep the Decimal Places they were saved with.
- **dfm**: The right-click menu on the DFM Ratios averages table now stays inside the window and shows only the actions that apply.
  - Right-clicking near the bottom or right edge no longer cuts the menu off.
  - Right-clicking a formula label no longer offers Copy Value or Add Cell Notes, and the label is filled blue while the menu is open.
  - The Load Settings From Another Method button on the Details tab shows a fill only on hover.
- **excel add-in**: Excel add-in 4.0.2 recalculates the whole workbook after Refresh Workbook or Refresh Worksheet, so formulas that depend on Arco results no longer keep stale values.
  - The 4.0.1 file released earlier the same day failed to compile on every Arco formula because two constants were declared below the first procedure of their module; 4.0.2 replaces it, and the build check now compiles the whole VBA project.
  - A refresh used to recalculate each sheet once in order, which left formulas fed through more than one sheet, or any dependent formula in Manual calculation mode, showing values from before the refresh.
  - Every formula in the refreshed workbook is now marked and recalculated in one dependency-ordered pass once the Arco cells hold their new values.
  - Other open workbooks are recalculated no further than pressing F9 would.
