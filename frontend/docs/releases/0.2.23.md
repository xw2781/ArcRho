# Release 0.2.23

Released on 2026-06-08.

## User-Facing Changes

### Features
- **dataset**: Added Project Instance row-menu Add options for dataset drafts and placeholder method workflows.
- **project instance**: Added Project Instance dataset table filter chips while keeping the cached-dataset eye toggle separate.
  - Filter chips can be cleared from the toolbar with the left-side x or by right-clicking the chip.
  - Hovering a filter chip shows the full selected value list in an app-styled tooltip.
  - The cached-dataset eye toolbar is transparent and aligned with the dataset table inset.
  - Floating Project Instance window title text no longer shows a native browser tooltip.

### Improvements
- **project instance**: Dataset table selections can now move with Up and Down arrow keys and open the selected row with Enter.

### Fixes
- **dataset**: Fixed Dataset Save and Cancel controls overlapping large Data tables.
- **dataset**: Fixed existing Dataset Viewer instances getting stuck while loading after the editable instance name update.
- **project instance**: Aligned the Project Instance cached dataset count with the visible cached dataset rows.
- **project instance**: Fixed Project Instance dataset row selection for names that differ only by special characters.

## Internal Notes

- **dataset**: Dataset instance indexes now store method type as a dataset file property instead of a separate methods section.
- **project instance**: Split the Project Instance script into focused modules for easier maintenance.
