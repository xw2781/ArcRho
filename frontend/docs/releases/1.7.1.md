# Release 1.7.1

Released on 2026-09-17.

## User-Facing Changes

### Features
- **project instance**: Right-clicking the minimized-window bar in Project Instance opens a menu that restores, minimizes, or closes every nested window at once.
  - Restore windows brings every minimized window back to where it was.
  - Minimize all sends every open window down to the bar.
  - Close all windows closes the windows with nothing unsaved and leaves any window with unsaved changes open, reporting how many stayed.
  - An action that has nothing to act on is shown greyed out rather than hidden.
- **DSV and DFM**: Added array functions, ArcRho dataset formulas, autocomplete, and an fx formula helper to DSV and DFM.
  - Use TAKE, INDEX, and TRANSPOSE with current or other-project/segment dataset calls; empty project and RC arguments use the current context.
  - Choose functions and argument values, preview results, and insert a formula draft from fx.
  - Typing [ offers dataset names in DSV, and range selections show their first cell in the formula bar.
  - Links to other projects and segments update through explicit refresh.

### Improvements
- **macros**: Combined adjustment notes now say which growth basis a line used, as in "Apply growth adjustment (counts) of 1+4.26% = 1.0426;".
  - Counts, incurred and paid each get their own bracket after the adjustment name.
  - The BIR51+UMBIR51 special case reads "Apply growth and BI limit adjustment (incurred) of ...".
  - The macro writes the new wording on its own, so it works without waiting for an app build.
  - A ResQ import reads the new wording back into the matching growth vector after the next app build, and still reads the older notes.
- **dataset**: A dataset produced by the Engine, a formula, or a method can now have the way it is shown changed and saved, even though its values still cannot be edited.
  - Origin Length, Development Length, Cumulative, Development/Calendar, Transposed, the subtotal row, Number Format, Decimal Places, and Notes all save on these datasets.
  - Such a save touches nothing but the dataset's settings file and refreshes no dependent object, so it finishes immediately.
  - The status line no longer shows the note about writing values into the stored period on a dataset whose cells cannot be typed into.
- **dataset**: The Data tab's formula bar now shows "Select a cell to edit the formula" instead of an empty box when no cell is selected.
  - The hint is shown in a lighter, italic style so it reads as a notice rather than editable content, and in dark mode the bar keeps its normal panel tone instead of the darker input fill.
- **dataset**: Saving is faster on a long chain: each affected item is now redone once, in the order it depends on, instead of once for every route that reaches it.
  - The save works out everything it affects up front, then refreshes it in that order, so an item several methods read is no longer rebuilt several times.
  - The saving popup still names each item as it is refreshed, and the server log now records how many of the affected items were refreshed and how long each kind of method took.
- **result selection**: The Result Selection Chart tab now zooms to a dragged rectangle and restores the full view on a double-click.
  - Removed the Chart tab header so the plot and its legend use the whole panel.
- **dataset**: The Saved notice now lists only the dependent methods whose values changed and need review, not every dependent the save rewrote.
  - A dependent that was recalculated but kept the same values stays green and is left out of the list.
  - Dependents changed deeper down the chain, such as a Result Selection refreshed after a BF method, are listed too.
- **dataset**: Saving is faster: the dependent refresh no longer rebuilds the reserving class index after every method it recalculates.
  - The walk reads the list of existing datasets once and reuses it for every nested step; the index is still rebuilt once at the end.
- **dataset**: A dataset reference now reads its source at the period the grid is shown at, so the position in the reference means what it looks like on screen.
  - A reference typed into a yearly grid takes yearly figures from a source held monthly instead of that source's first months.
  - A source that cannot be shown at the grid's period is refused with the reason rather than answering with its own rows.
  - The ArcRhoVec and ArcRhoTri function forms still name their own period and are unchanged.
- **excel add-in**: Excel add-in 3.0.0 keeps saved workbook results until an explicit refresh.
  - Shared workbooks reopen with the last saved ArcRho values without contacting the server.
  - Refresh commands read permanent datasets as published and reuse unchanged temporary generated results.
  - Removed the always-refresh setting and preserved saved results when a refresh fails or is cancelled.

### Fixes
- **notes**: Notes panels reliably remember their last resized dimensions and have a wider minimum width across Dataset Viewer and method pages.
  - Opening or hiding a tab and resizing its window no longer overwrite the preferred notes size.
  - The minimum notes width is now 480 pixels, capped by the available window width.
- **notes**: Notes panels keep their dragged size across restarts and window sizes instead of sometimes opening at the minimum width.
  - The size is now a desktop preference, so File > Restart, Clear Cache & Reload, and a fallback app port no longer forget it.
  - Adjusting only the height no longer resets the width to the minimum, and a height adjustment in a window too narrow for the panel keeps the wider width for when the window is maximized.
- **bf**: The BF Method table now fills the available page height, removing the unused gap below the table.
  - Added top spacing above the Method toolbar so its group titles remain fully visible.
- **dataset**: Fixed number-format saves being rejected when generated datasets are opened from Project Instance or Result Selection.
  - Generated dataset values remain protected while display settings and notes can be saved.
  - Display-only saves preserve the modified timestamp, user name, and audit history.
  - Temporary and explicitly read-only windows still block saves.
- **dataset**: The Saved notice that lists updated dependent datasets now looks the same on every page and scrolls with the mouse wheel.
  - The list uses the app's framed scrollbar instead of whichever scrollbar the host page happened to show.
  - Wheel scrolling over the list moves the list; the page behind the notice still stays put.
- **dataset**: Clear data is back on the Dataset Viewer Data tab's right-click menu, below the copy and paste items.
  - It sets every editable cell of the whole table to 0, whatever is selected, which frees the length controls again on a hand-entered dataset.
  - The item is hidden on a table that cannot be edited.
