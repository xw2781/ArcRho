# Release 2.0.0

Released on 2026-10-06.

## User-Facing Changes

### Features
- **arcode**: Arcode reopens your file tabs on start, and gains a Restart item, an AutoSave switch, and code folding in notebook cells.
  - Open files and the active tab are saved and restored; New Arcode Window still starts empty.
  - File > Restart relaunches Arcode.
  - AutoSave, off by default, saves a notebook 1 minute after an edit or output change.
  - Notebook cells fold long dicts, lists and functions.
  - Keyboard Shortcuts moved from the notebook toolbar to the Settings menu.
- **dfm**: Added an interactive DFM guide with in-page component markers and concise contextual help across all tabs.
  - Use the compact circular help button to toggle component outlines; hover components or focus numbered markers for one short tooltip at a time.
  - Hints explain double-click ratio charts, component-specific right-click menus, curve editing, chart interactions and keyboard shortcuts.
  - The guide keeps the full working page width, with no side panel, and does not change the method or its save state.
- **table appearance**: Customize font family, size, bold and italic by table section alongside text, fill and border colors.
  - The table context menu now opens Table Appearance, with independent font controls and resets for each section.
  - Font and size fields show the values currently in use, including inherited settings, instead of Default or Auto placeholders.
  - Appearance preferences update immediately and remain separate from method data.
- **ArcBot**: ArcBot prepares chats in the background, shows commands and output, and collapses completed work into a concise reply.
  - Dictate into the composer using local Windows speech recognition and review the text before sending.
  - Read methods across the active project through a read-only tool, including closed methods; edits still require the original page to be open and active.
- **ArcBot**: ArcBot can now keep several OpenAI and Claude accounts and switch between them from Settings.
  - The Account section is one picker listing every OpenAI and Anthropic account; the account you select is used for every chat, new or existing, and its provider decides which models you can pick.
  - Its menu switches accounts, signs in or out, and removes added accounts; Add Account… takes a name and opens the sign-in window, and each added account keeps its own sign-in, separate from your main one.
  - Changing the account or model in a chat adds a short note, and warns that the next reply may be slower when the chat was active in the last hour.
  - The Current Chat Login row in Settings shows the account in use.
  - ArcBot notices when sign-in finishes, and switching applies to the next request.
- **ArcBot**: ArcBot can now read the methods and datasets of any project on the server when you ask, and it still defaults to the project that is open.
- **arcbot**: ArcBot's Skills menu now lists skills the team keeps on the server, starting with DFM Diagnostics for the open DFM.
  - DFM Diagnostics opens the diagnostic triangle, flags unusual early values, suggests ratio selections, and reviews last quarter's excluded ratios.
  - A skill only advises: it never changes a method, and it needs the matching window open.
  - Show Diagnostic Triangle now finds a DFM's triangle in the skill's JSON mapping instead of the old workbook.
  - Claude models can use project reads and macros while a skill runs.
- **project settings**: Project Settings can now lock a project so no user can save its methods or datasets or change its imports until it is unlocked.
  - Each user's own layout preferences, such as column widths, still save in a locked project.

### Improvements
- **arcode**: Notebook cells can import Python files saved beside the notebook, and no longer stop after 60 seconds.
  - Each cell run sends its notebook's folder, so a module next to the notebook imports the way it does in Jupyter.
  - A cell runs until it finishes or Stop is pressed.
- **arcode**: Find and replace searches the active cell while editing, or the whole notebook in command mode.
- **arcode**: Notebook Python cells now show function documentation, argument hints, and runtime completions without clipping popups at cell boundaries.
  - Run ?function_name to display documentation for built-in, imported, or notebook-defined functions.
- **dfm**: DFM now always shows N/A cell borders; removed the Hide/Show N/A Borders menu option and its preference.
- **user guide**: Added Help → User Guide with a Gateway-hosted screenshot guide covering the app's workspaces and integrations.
  - The refreshed guide uses Project Page terminology and a smaller Commercial Auto demo with a fictional reviewer.
  - Screenshots enlarge for closer inspection and walkthroughs let readers compare each interaction.
  - The guide supports narrow screens, printing, and an offline folder copy.
- **ArcBot**: Replaced the Dictate text button with a compact microphone icon and a visible active-dictation state.
- **ArcBot**: ArcBot now offers the current Claude models, picks up new OpenAI and Claude models on its own, and starts new chats on GPT-6.1-Sol at Medium reasoning.
  - Claude choices are Fable 5.1, Opus 5.5, Sonnet 5.5, and Haiku 4.5, read from Anthropic when you are signed in to Claude; Sonnet 5.5 at Medium is the Claude default.
  - The Model and Reasoning pickers are now app-styled lists with provider groups, a quiet Default tag, a check on the current choice, and keyboard control.
- **arcbot**: ArcBot's work log now says in plain words what each step does, and Claude replies show their progress while the model thinks.
  - A step reads, for example, "Reading DFM \"C 22 - CWOP DFM\" from NJ_Annual_Prod_202605_Fake" or "Ran the Show Diagnostic Triangle macro" instead of a tool name.
  - While a Claude model thinks, a short summary of its thinking appears in the work log and the reply bubble counts the thinking tokens so far.
  - A Claude reply now streams into the chat as it is written instead of appearing all at once at the end.
  - Section headings in a reply show as headings instead of "##" marks.

### Fixes
- **app updates**: Keep the splash screen download status on one centered line during app updates.
- **excel add-in**: Excel refresh reads a quarterly method output, such as a Result Selection, at 6 or 12 months from the copies the method saves, and a failed refresh no longer stops with a status bar error.
- **arcode**: Notebook text progress bars now update in place instead of accumulating repeated progress lines.
  - Notebook output uses the normal text color instead of red, including stderr progress messages.
- **dataset**: A formula vector such as Expected Net Loss % * Earned Premium reopens at the period you last saved it at, and keeps that period when another dataset it depends on is saved.
  - Saving a dataset that a formula vector depends on no longer resets the period the vector is shown at.
  - Opening a formula vector shows the period you last saved, for example 12 months over quarterly data, when that period has been calculated.
- **dataset**: A formula dataset such as Expected Net Loss % * Earned Premium now always recalculates from current copies of its inputs, and a save tells you when a dependent could not be refreshed and why.
  - After a source table import, a quarterly formula no longer reads an out-of-date quarterly copy of an annual Engine dataset.
  - A source table import rebuilds a vector at the period it is shown at instead of resetting it to 12 months.
- **server connection**: More project actions work without access to the shared drive.
  - Project Instance JSON previews load read only from the server; ordinary Arcode editing is unchanged.
  - Active DFM macros save through the server, and dataset loads recover their location after a server restart.
  - Adding a server no longer requires its shared folder to be accessible.
- **dfm**: A quarterly or monthly DFM now refreshes when its Engine-generated input has blank columns past the valuation date, instead of being refused for incompatible development geometry.
  - The blank padding the Engine adds to a triangle is ignored; a file with values past the method's development labels is still refused.
- **app**: Two Arco apps open on one PC no longer disturb each other.
  - Opening a second app no longer shuts down the first one's server; it starts its own when it cannot share it.
  - A macro's progress window, messages and review table stay in the app it was started from.
  - Closing the app that started a macro while its review table is open ends the macro as a cancelled review instead of an error.
  - Closing the last app window stops its server, whichever app started it.
- **ArcBot**: ArcBot now reads the reserving class open in the window unless asked about another class or the whole project, and its project reads no longer fail when Python is installed under a folder with spaces.
- **arcbot**: ArcBot's Claude models now work with a Claude subscription sign-in: each reply runs through the Claude Code app instead of failing with a rate-limit or certificate error.
  - Claude's model list also connects on PCs whose security software inspects web traffic.
- **ArcBot**: ArcBot now installs the Claude CLI by itself, so signing in to Claude works on a computer that does not have it.
  - The install starts in the background when ArcBot's account list opens, and a sign-in waits for it before opening the sign-in window.
- **ArcBot**: The context ring's tooltip now shows the chat's model and reasoning effort, and the dictate and attach buttons use the same tooltip style.
- **ArcBot**: Kept ArcBot composer controls on one row by increasing the chat window's minimum width.
- **ArcBot**: ArcBot Repair now reports failed npm installations instead of incorrectly claiming installation completed.
  - Repair verifies that the Codex launcher was created in its per-user folder and can start before reporting success.
- **ArcBot**: Tidied ArcBot's work log: each command shows as one line that expands to its full output, filler status lines and the composer's working label are gone, and a request may now run for up to 30 minutes.
- **dfm**: DFM refresh now advances development labels with the valuation date while preserving selection patterns and exclusions.
  - Input values, ratios, averages, and results recalculate using the refreshed triangle, and the method is marked for review.
- **project settings**: Source refresh date-range errors now explain which date settings to correct instead of showing a technical calculation error.

## Internal Notes

- **build**: Added a launcher that starts Arcode alone in dev mode.
- **automation**: Agents can now look at and drive an Arco window without taking over the whole computer.
  - The agent's input goes only into Arco; the real mouse pointer stays with the person at the desk.
  - While an agent is in control, Arco shows an edge glow, the agent's own pointer, and a banner naming the agent and its current step.
  - Clicking, typing, or scrolling in Arco, or pressing Ctrl+Alt+Esc, pauses the agent at once; the banner's Resume and End buttons decide what happens next.
