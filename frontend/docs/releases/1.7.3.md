# Release 1.7.3

Released on 2026-09-20.

## User-Facing Changes

### Features
- **project instance**: Filter dependency chains by Status, Category, and Method Type directly in the graph toolbar.
  - Matching datasets keep their inputs and dependents visible; unrelated branches are hidden.
- **project instance**: Set method outputs to Reviewed or reveal their dataset-table rows directly from the dependency graph context menu.
- **project instance**: The dataset table's grouping and filters can be saved to a file and loaded back.
  - Right-clicking the dataset toolbar offers Save Group And Filter Config and Load Group And Filter Config.
  - Dropping that file anywhere on the dataset panel loads it as well.
- **project instance**: Shortcuts in the project instance path panel can be saved to a file and loaded back into any project.
  - Right-clicking the Shortcut section header offers Save Shortcut Config and Load Shortcut Config; the file holds the shortcut paths, their nicknames, and the folders they sit in.
  - Dropping that file anywhere on the path panel loads the shortcuts too, keeping only the paths the open project has and asking before replacing shortcuts already there.

### Improvements
- **project instance**: Show the shared yellow Needs Review triangle before the method label, remove filter-value labels, and keep nonmatching chain cards at normal emphasis.
- **project instance**: Simplify filtered dependency graphs with Show matched items only enabled by default and always hide isolated datasets.
  - Remove Show all; datasets and method outputs with no precedents or dependents stay hidden.
  - Uncheck Show matched items only to include surrounding chain context; dashed arrows connect matches through hidden datasets.
- **project instance**: Use the dataset table's filter menu in the dependency graph and remember the user's last filter choices.
  - Search values, select All, or right-click to exclude a value using the same menu as the PI dataset table.
  - Remember Status, Category, Method Type, and Show matched items only on this PC; keep the checkbox beside Clear filters.
- **project instance**: The dependency graph button in the dataset toolbar has a new branching icon.
  - It shows a trunk with one line branching away from it, so it no longer looks like the generic org-chart icon used elsewhere.
- **project instance**: The Dependency Graph window now shows only datasets listed in the reserving class index.
- **project instance**: The icon buttons in the path panel's Shortcut and All Paths headers now line up with the star column beneath them.
