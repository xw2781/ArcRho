# Release 0.2.19

Released on 2026-06-02.

## User-Facing Changes

### Features
- **arcbot**: ArcBot now supports Anthropic Claude models alongside OpenAI models, routing requests through the Claude CLI OAuth credentials stored by claude login.
  - Added Claude Opus 4.8, Claude Sonnet 4.6, and Claude Haiku 4.5 to the model selector under an Anthropic group.
  - Claude requests are authenticated using the OAuth token in ~/.claude/.credentials.json written by the Claude CLI, with no separate API key required.
  - Switching to a Claude model re-checks credentials automatically; the sign-in button opens claude login in a terminal.
  - Reasoning/thinking effort field is hidden for models that do not support it; for Claude models the label reads Thinking instead of Reasoning.
  - All models share the same session context, message history, attachments, and active-tab context flow.
  - An inline warning appears in the settings panel when a high-token configuration is active: high or extra-high effort, or a top-tier model (GPT-5.5, Claude Opus 4.8).
- **shell**: Added PC-local Restore Pages history for the latest active pages, including Project Instance nested window state.

### Improvements
- **dataset**: Moved Dataset Type into the dataset Details section below Name.
- **project-instance**: Added a Clear All button to Project Instance dataset table filter popovers.

### Fixes
- **project-instance**: Preserved cleared Project Instance dataset table filters after reload.
