# Release 1.0.5

Released on 2026-06-18.

## User-Facing Changes

### Features
- **dataset**: Added saved Dataset Data tab number formatting controls for grid and chart values.
  - Decimal Places now persists in dataset sidecar JSON.
  - Number Format is editable while still offering common preset suggestions.
  - Decimal Places now uses a wider custom spinner with SVG up/down controls.
- **dataset**: Added Dataset sidecar audit logs for inserts and value updates.
  - Dataset audit logs keep the latest 50 records in the sidecar JSON.
  - The Dataset Audit Log tab now displays event date, action, change info, and Windows user.
  - Event dates use a compact 12-hour format such as 6/15/2026 11:17:51 AM.
- **arcode**: Added a Snowflake SQL editor in Arcode with local SQL files, connection profiles, query execution, and result previews.
- **macro**: Added Python macro helpers for ArcRho UI automation commands.
  - Macros can show an ArcRho message box from Python.
  - Macros can open a Dataset Viewer window in the active Project Instance page for the currently selected reserving-class path.
- **python-api**: Added COM-style Python UI window objects for controlling ArcRho Project Instance floating windows.
  - Python scripts can now open a dataset window, inspect its properties, and activate, maximize, restore, minimize, or close it through an object API.
- **result selection**: Added the first Result Selection method window for weighted vector selections from Project Instance.
  - Project Instance can create Result Selection objects from eligible vector datasets and reopen saved Result Selection method outputs.
  - The Method tab supports source datasets, row-level weights, selected ultimate calculation, and an optional ultimate-to-basis ratio column.

### Improvements
- **project instance**: Project Instance floating windows now minimize from titlebar right-click instead of dragging to the hidden-tabs area.
- **dataset**: Made the Dataset Chart tab resize automatically while docked in the normal tab area.
- **shell**: Updated shell and Arcode tabs to use crisp SVG close icons, removed the blue drag insertion line, and kept the detached-tab preview above floating windows.
- **arcode**: Removed the New Notebook command from the Arcode File menu.
- **arcode**: Added Arcode home cards for creating Python, notebook, and SQL files in the selected workspace folder.
- **arcode**: Moved Arcode recent files from the home page into a File menu submenu backed by local settings.
- **arcode**: Arcode now remembers the last selected workspace folder in local settings.
- **dataset/dfm**: Expanded Dataset and DFM Details input fields to use wider editing space.
- **dfm**: Left-aligned the value in the DFM Details Decimal Places box.
- **dfm**: Polished the DFM Details origin and development length dropdown menus.
- **dfm**: Removed the Load Settings From Template button from the DFM Details page.
- **project instance**: Removed DFM and Result Selection prefixes from Project Instance floating window titles.
- **result selection**: Removed the path bar from the Result Selection method window.
- **arcode**: Restored open Arcode tabs automatically after Clear Cache & Reload.
- **dfm**: Softened the DFM Ratios cell note popup corners to better match modern Windows styling.
- **dfm**: Kept the DFM Ratios formula bar frame aligned to the average-formula summary table while its controls stay clamped inside the DFM viewport during horizontal scrolling.
- **macro**: ArcRho macros now load from the dedicated Documents\ArcRho\macros folder.
- **macro**: ArcRho macro message boxes can now be dragged as floating windows.
- **python api**: Added Python UI automation helpers for external notebooks and scripts.

### Fixes
- **dataset**: Prevented Dataset refreshes from using invalid origin and development length combinations.
  - Increasing Development Length above Origin Length now automatically raises Origin Length before the triangle refreshes.
- **dfm**: Updated the DFM Details Decimal Places input so direct typing refreshes Ratios tab number formatting immediately.
- **dataset**: Made Dataset Details panels resize with the window like DFM Details panels.
- **dataset**: Kept Dataset Details fields aligned with their labels when the window is resized very small.
- **dataset**: Stopped Project Instance from showing duplicate cached dataset rows when a sidecar name and cache filename differ only as aliases.
- **dfm**: Updated the DFM Data tab so input triangle values use the selected triangle sidecar number format.
- **dfm**: Prevented DFM Details Decimal Places edits from being reverted by the embedded Data tab refresh path.
- **dataset**: Kept project instance dataset context submenus visible when opened near the bottom of the window.
- **result selection**: Made the Result Selection Method grid rows use compact DFM-style table sizing.
- **result selection**: Fixed Result Selection Method tab grid sizing and origin labels to match the selected origin length.
- **result selection**: Stored Result Selection origin labels in the output sidecar and tightened the Method grid text size.
- **result selection**: Fixed Result Selection Method tab origin labels so quarterly outputs use quarterly header labels instead of stale annual labels.
- **arcode**: Improved Arcode tab label and close button visibility for long notebook names.
- **dfm**: Stopped newly opened DFM tabs from showing unsaved changes before any edits are made.
  - DFM tabs now track unsaved changes from user edits instead of model recomputation during method load.
  - After a user edit, manually changing the value back still leaves the tab unsaved until Save or Cancel.
- **dfm**: DFM input-triangle loading now lets generated cached triangles build missing period shapes while keeping manual inputs local-cache-only.
  - Manual and imported input triangles can still load exact caches or derive coarser shapes from finer local caches, but requests for finer detail are rejected.
- **dfm**: Fixed closing dirty DFM tabs from the tab close button and Ctrl+W.
- **dfm**: Fixed DFM User Entry formula highlighting so quoted average-formula names only match the exact referenced row.
- **macro**: Macro Python files saved with a UTF-8 BOM now load and run correctly.
- **project instance**: Fixed Project Instance DFM windows showing unsaved changes immediately after opening and closing after discard confirmation.
  - DFM windows now force a clean-state sync after programmatic method load.
  - Clicking Yes in the unsaved-changes confirmation now clears the floating window dirty flag and closes the window.
- **shell**: Fixed Clear Cache & Reload so it reports failures and falls back to a browser reload when the desktop host cannot reload the shell.

## Internal Notes

- **dataset**: Dataset sidecars now use dataset_name and dataset_type as the only persisted name fields and no longer accept legacy root aliases.
