# Release 1.7.0

Released on 2026-09-16.

## User-Facing Changes

### Features
- **dfm**: Copy and apply green selected formula patterns between DFM summary tables over their overlapping range.
- **dataset**: Added basic Excel-style functions to the compact Data formula bar.
  - Supports IF, IFERROR, SUM, MAX, MIN, MEDIAN, AVERAGE, COUNT, ABS, ROUND, comparisons, and nested numeric formulas.
  - Plain numbers can be entered without an equals sign, and constant-only formulas remain formulas after saving.

### Improvements
- **dfm**: Limit ratio and selected formula pattern copy/apply to highlighted columns, defaulting to all columns when none are highlighted.
- **dependent propagation**: Keep reviewed methods green when full downstream recalculation leaves their meaningful content unchanged.
  - Every downstream object still recalculates and updates its timestamp, user, and audit metadata.
  - Changed method content or cached values require review; existing review alerts remain until an explicit save.
- **dataset**: Simplified the Data menu with muted shortcut hints and added a persistent, full-width formula panel for manual input datasets.
  - The formula panel has square corners and the same light grey border as the data table.
  - The Data toolbar has a small top inset and no horizontal padding to align with the formula panel, plus a small left inset for Cumulative.
- **dfm**: Added Paste Value to User Entry cells in the DFM Ratios summary menu and renamed Copy Value.
  - Paste Value uses the existing numeric grid paste validation and is available in Edit mode.
- **propagation**: Route downstream refresh submission, progress, and busy checks through Gateway instead of client network-drive access.
  - Repeated submissions keep their existing job status without requeueing.
  - Unavailable Gateway checks fail clearly without falling back to network-drive polling.

### Fixes
- **project instance**: Keep highlighted dataset rows and table scroll position after saving, including when save refreshes overlap.
- **about**: The Release History window now lists the version you are running.
  - The list used to stop one version short, because each version's notes were written only after its installer had been packaged.
  - Every build now writes its own notes before packaging them, so the newest entry is the installed version.
- **dfm**: Allow ratio patterns to be applied across different triangle shapes, ignoring unmatched cells with a concise status-bar warning.
- **dataset**: Refreshing a calculated vector now keeps its quarterly and annual cache views current.
- **dataset**: Saving an unchanged dataset now refreshes its downstream datasets.
- **dataset**: Allow user saves only for manual/input datasets; calculated, engine-generated, and method outputs remain read-only in the Dataset Viewer.
- **dataset**: Keep the Dataset Viewer Save button label readable when hovering over an unchanged dataset.
- **dependent propagation**: Every eligible dataset or method Save recalculates the full downstream chain, updating review flags, timestamps, and user metadata even when values are unchanged.
- **result selection**: Downstream Result Selection outputs now record their refresh time even when values are unchanged.
- **result selection**: Propagation now refreshes downstream Result Selection methods when an upstream output needs review.
