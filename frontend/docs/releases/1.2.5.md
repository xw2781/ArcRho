# Release 1.2.5

Released on 2026-08-08.

## User-Facing Changes

### Features
- **arcode**: Added an Arcode home Terminal card that opens a desktop terminal in the selected workspace folder.
  - The Terminal card appears in the Other group with the JupyterLab terminal icon.
  - The Electron host opens Windows Terminal when available and falls back to PowerShell.
- **project instance**: Added Help menu actions to open the active Project Instance dataset JSON and sidecar files in VS Code.
- **ArcBot**: Added an ArcBot SQL Format Validation skill for Arcode SQL tabs.
  - Typing / in the ArcBot composer now opens a Skills menu.
  - The SQL skill shows a unified review diff and requires confirmation before replacing the active editor text.
  - The SQL review diff uses old/new line-number gutters with addition and deletion markers.
  - The SQL review dialog can be dragged by its header, and optional AI review runs in the ArcBot chat with a visible user prompt, thinking message, and progress animation.
  - When SQL text is selected in the active editor, the skill reviews and replaces only that selected range.
  - The SQL review dialog is resizable, and activating the ArcBot chat panel brings the chat back above the diff window.
  - Whole-file SQL reviews now explicitly ask ArcBot to inspect every statement block, not only the first section.
  - The SQL review diff has its own visible vertical and horizontal scrollbars.
  - The optional AI review now groups material findings into syntax/formatting and performance/optimization sections without forcing notes for every SQL block.
  - SQL AI review responses include a clickable link to the local SQL coding standards page.
  - SQL AI review findings now request original SQL line numbers before each issue and avoid duplicate standards links.
  - The SQL review diff now uses clearer red/green rows with sticky line-number gutters while horizontally scrolling.
  - SQL AI review responses now avoid visible Markdown heading markers and render the main issue group labels in bold.
  - The SQL review diff now extends red/green row backgrounds across the full horizontal diff width, including short or blank changed lines.
  - The deterministic SQL formatter now preserves full-line -- comments without splitting or reindenting them.
  - The SQL review diff now syntax-highlights SQL keywords, functions, datatypes, strings, comments, numbers, and bracketed identifiers.
  - The SQL review diff opens as soon as the parser-backed preview is ready while optional structured AI review continues in ArcBot.
  - ArcBot chat responses now syntax-highlight SQL-looking inline code plus fenced SQL, MSSQL, and T-SQL code blocks with the same SQL colors as the review diff.
- **arcode**: Split Arcode notebooks and plain scripts into separate notebook and code editors.
  - Notebook files now open in the renamed notebook editor.
  - Plain script and text files now open in a simpler Monaco-based code editor with save, format, and Python run output.
- **dataset**: Dataset Details now lists dependent datasets and lets Project Instance users open them directly.
  - Formula and Dependents now align with the other Dataset Details fields instead of sitting inside a separate frame.
  - Formula components and operators reuse the rich token style from the Reserving Class Type formula editor.
  - Empty Formula and Dependents boxes no longer show placeholder text; Formula stays compact and grey.
  - Clickable formula chips open the related dataset, or the related DFM or Result Selection method window when the component is method-backed.
  - Dependent datasets now use richer chip styling inside the Dependents box.
  - Hovering a dependent dataset shows its formula with the same rich token formatting when the formula is available.
- **dfm**: Added a Task Designer tab for showing live DFM validation progress.
  - DFM tabs and scripts can open Task Designer as a live progress monitor.
  - Task Designer is now a normal shell tab that starts in floating pop-out layout and can be docked to the tab strip.
  - Task Designer now shows only live task rows and removes UI-side macro compose, preview, save, run, and stop controls.
  - Task Designer task rows now keep long text to two lines and show macro messages in a dedicated Comments column.
  - Running Task Designer rows now show a Dataset-style sweep spinner in the Duration column and an animated activity indicator in the Status column until the task finishes.
  - Running task duration refreshes now update elapsed text in place so row animations continue smoothly.
  - Clicking a Task Designer row now opens a nested floating details window with full comments and task properties.
  - Macro execution now provides __file__ to wrapper and child macros so sibling macro imports work consistently.
  - Validation macros can update task rows live through the ArcRho Python UI API or injected Task Designer helper.
- **scripting**: Added UI automation support for a user-managed Import from ResQ macro that targets the selected Project Instance reserving-class path.
  - The macro shows an ArcRho message box when the ResQ COM connection fails.
  - Successful imports report the imported dataset count and auto-close the message after three seconds.
- **scripting**: Added macro scope tags and an active-context filter to the Macro window.
  - Macros can declare Scope metadata for DFM, Result Selection, and Reserving Class contexts.
  - The Macro window filter can hide macros that do not match the active tab or selected Project Instance reserving-class path.
- **automation**: Added shell progress dialogs for Python UI automation commands.
  - Python macros can now open, update, close, and resize a draggable progress window with a close icon, visible progress bar, and one-decimal percentage text.
  - The ResQ import macro reports one current dataset or method detail at a time instead of filling the Macro window with import logs.
- **result selection**: Added Result Selection Method sync for comparing local JSON with ResQ JSON.
  - The Method toolbar now includes a ResQ Sync action with a side-by-side version comparison.
  - The ArcRho bridge can now smart-match normalized ArcRho Result Selection names to nonstandard ResQ instance names, export JSON using OriginCount, and write local weights, ultimate overrides, Origin Length, and notes back to ResQ.
  - The comparison cards focus on version details and surface bridge status or error JSON instead of rendering it as an empty method.
  - The toolbar layout was tightened into compact grouped controls.
- **manual**: Added a multi-page standalone ArcRho user manual that can be opened directly from the frontend folder.
  - The manual now uses separate topic pages for shell navigation, project setup, project instance workflows, datasets, DFM, Result Selection, Workflow, macros, ArcBot, Arcode, Python API, Excel add-in usage, ResQ migration, and troubleshooting.
  - Embedded HTML UI examples use sample data, highlighted controls, and simulated interaction animations to show common ArcRho screens without requiring a running app.
- **automation**: Added Python UI automation support for reloading the active Project Instance dataset table after scripts update datasets.
- **bornhuetter ferguson**: Added a Bornhuetter Ferguson method page with Project Instance routing, method table calculation, output vector save, sidecar metadata, notes, and audit-log restore.
- **build**: Added an optional Windows installer step to register the ArcRho Excel add-in automatically.
  - The add-in option is checked by default.
  - Setup detects an existing ArcRho Server folder across drive roots, or asks the user to choose the root drive before deriving the ArcRho.xlam path.
  - The custom NSIS include now loads Modern UI definitions before rendering the Excel add-in options header.
  - Excel add-in releases now preserve valid Office package paths and validate required workbook parts before publishing the XLAM.
  - Setup now runs the known-working InstallNetworkXLAM macro inside an isolated Excel instance and verifies the installed add-in without weakening Trust Center settings.
- **bornhuetter ferguson**: Added a Chart tab comparing DFM implied, selected prior, and Bornhuetter Ferguson ultimate values by origin period.
- **bornhuetter ferguson**: Added multiple weighted prior datasets and Result Selection-style weight formatting controls to Bornhuetter Ferguson.
  - Double-clicking an Index weight toggles it between 0 and 1, while Effective % weights remain read-only.
- **dfm**: DFM User Entry formulas now support refreshable external Excel ranges with highlighted spill cells.
- **dfm**: DFM Ratios User Entry rows now accept single values and rectangular ranges pasted from Excel.
- **dfm**: Added Select and Edit modes with S and E shortcuts so users can copy DFM Ratios cells without accidentally changing ratio choices.
  - The Ratios context menu starts with a command that switches to the other interaction mode.
- **dfm**: Added a Ratios context-menu option that shows or hides Data-tab values beside their DFM ratio columns.
- **dataset and bornhuetter ferguson**: Added Shift-click range selection between row labels or between column labels in shared spreadsheet tables.
- **method pages**: Added a consistent Audit Log tab to method pages using each output dataset's saved history.
  - Bornhuetter Ferguson, Result Selection, and DFM now share the Dataset Audit Log table, states, and scrollbar behavior.
  - Audit history refreshes from the output dataset sidecar without affecting unsaved method changes.
- **dataset and dfm**: Added reusable Excel Links workflows for Dataset Viewer and DFM.
  - Editable Dataset cells can load a cell or rectangular range from a full external Excel reference, clip oversized ranges to editable Triangle or Vector cells, and edit a link from a hover formula bar.
  - Linked Dataset cells use bold dark-green text, while unsaved Dataset entries no longer refresh the Project Instance disk-backed dataset inventory.
  - Links tables show current values, support Ctrl/Shift row selection, and provide Refresh all or Break all actions that operate on all rows or the selected rows while preserving current values when links are broken.
- **project instance**: Added a temporary Project Instance dataset view for safely previewing data-engine datasets.
  - Temporary view shows whether each data-engine dataset is already listed in the selected-path index.json.
  - Generated and derived temporary-view CSVs are retained in datasets/.temporary-view after the view closes, without creating sidecars, index entries, or index rebuilds.
  - The Temporary view control now states whether Temporary view is enabled or disabled and describes only the active mode.
- **project settings**: Data-processing rule When conditions now provide an is/is not dropdown for requested coverages.
- **dataset**: Added workspace-wide default number formats for newly generated datasets.
  - Project Instance now provides a gear-button editor for fallback and Dataset Type Name overrides shared across reserving-class paths.
  - ResQ migration and frontend-generated datasets now use the same global configuration.
- **arcode**: Arcode Run now automatically uses live ArcRho context for macro source without showing a separate run button.
  - ArcRho macro metadata and run_macro entry points are detected from saved or unsaved editor source; other Python and selections continue to run locally.
  - Toolbar command labels keep their full button frames at narrower editor widths.
  - Standalone Arcode now bundles the ArcRho Python API and proxies source runs to the open ArcRho desktop app.
  - Macro results stay pinned to the captured DFM and are rejected if its live state changes before apply.
- **project settings**: Added hover-only drag handles inside Enabled cells for reordering Data Processing Rules and persisted the displayed order in project JSON.
- **shell**: Added live Light and Dark color themes that can be switched from Settings without restarting the app.
  - The selected theme applies to open workspaces, floating windows, charts, Arcode, Monaco editors, and the next startup splash.
  - Project Settings and Project Instance now keep tree labels, table headers, controls, dialogs, and floating-window chrome readable throughout Dark mode.
  - The existing Light palette remains the default, while each local user's selection is restored on the next launch and survives Clear Cache & Reload.
  - Theme and recent-item submenus use a shared SVG chevron for crisp, consistent indicators.
- **result selection**: Added a Result Selection Chart tab for comparing every source and selected output dataset vector.
  - A right-side Columns panel can hide or show each plotted vector without changing method data.
  - Selected Ultimate is explicitly labeled, the final visible line stays selected on click, and right-click toggles between isolating one line and restoring all lines.
- **shell**: Added a tabbed File Explorer for pinning, browsing, and opening local folders and files.
  - A File Explorer card on Home opens or focuses the page as a standard ArcRho tab.
  - The page keeps customizable favorite folders on the left and the selected folder's file list on the right.
  - Saved folders can use custom nicknames and remain available after cache clearing or restart.
  - The details view supports navigation history, path entry, search, sorting, file metadata, keyboard controls, and automatic refresh.
  - Excel workbooks now offer an Open Read-Only action from the file context menu.
  - Home and Arcode now share the existing folder and common file-type icon assets.
- **berquist sherman**: Added annual B&S Settlement Rate and Case Reserve Adequacy methods with ResQ migration support.
  - Both methods reproduce the reference COL calculations and save a minimal method JSON, result CSV, and sidecar.
  - Project Instance can create, reopen, preview, and restore the two B&S method variants.
- **resq import**: Added a synchronous remote ResQ reserving-class import through a shared ArcRho Bridge worker.
  - The macro now stops before publishing when no fresh ResQ-connected Bridge worker is available.
  - Import progress now identifies ResQ scanning, ArcRho Engine submission and waiting, metadata finalization, index rebuild, and commit phases.
  - Generated datasets remain ArcRho Engine outputs while ResQ-stored methods are imported by the Bridge.
  - DFM Ratio Basis snapshots are read directly from the related ResQ DFM instead of requesting a shape-specific data-engine dataset.
  - Imports stage and validate the reserving-class folder before replacing existing data.
- **project settings**: Source Data can now import a raw table from SQL Server, and every project owns the imported table inside its own project folder.
  - Switch a project between a flat CSV file and a SQL Server table from the Source Data header, then enter the server, database, and table name in the SQL Server panel.
  - SQL Server connects with your Windows account and stores no credentials on the ArcRho Server; the SQL Server login option is a placeholder and is not available yet.
  - Test connection reports the target table's column count before you import.
  - Both import routes write the same project-owned table at <project>\source\master_table.csv, and ArcRho now reads that copy everywhere instead of the external CSV path or the SQL Server table.
  - Existing CSV projects keep working with no action: the copy is created automatically and re-copied whenever the external file changes.
  - The Source Data details panel shows what the imported table came from, when it was imported, and by whom.
- **macro**: Added a Macro Library pop-up window for browsing and loading shared team macros from the ArcRho Server.
  - The macro panel header has a Library button that opens a separate floating Macro Library window listing shared macros from the server's shared\macros folder with version, release note, and install status (New, Update, Loaded, Differs).
  - Load copies the selected macro into your local macros folder; a differing local copy asks before it is replaced.
  - Macros continue to run only from your local macros folder, so an unreachable library never blocks existing macros.
- **berquist sherman**: Rebuilt the B&S Settlement Rate Adjusted Paid Claims view as a ResQ-style selection grid with per-cell estimator choices, Loess smoothing with an adjustable span, and the shared method-table styling.
  - The Method views follow the ResQ sub-tab order: Paid Claims, Numbers Closed with the Ultimate column, Proportion Settled, Selected Numbers Closed, and Adjusted Paid Claims, each with its ResQ caption line.
  - Each origin period now shows Unadjusted, Pairs, All, Loess (n), and Selected rows; click a value to select one cell, click a row label for the origin period, or Ctrl+Click a row label for the whole triangle.
  - The accident year and estimator labels are centered in the label column, matching the other calculation views.
  - The Proportion Settled tab matches ResQ: click a triangle percentage to select it per development period, type custom values into the Selected row, and right-click for Select Leading Diagonal.
  - Added the Loess estimator with a Loess Span stepper; the span is saved with the method and imported from ResQ.
  - The Method tab calculation views now use the shared nested tab styling, and the B&S table follows the DFM/BF/RS spreadsheet look with sticky headers and shared scrollbars.
- **dfm**: DFM Sync now reads ResQ method-level Notes and shows a Method Notes comparison in the sync review dialog.
  - The RPC bridge DFM read response carries ResQ method Notes as transient metadata, compared against the local output-sidecar notes with word-level diff highlighting.
  - Confirming a version applies its Method Notes state to the other side: choosing remote writes the ResQ note into the output dataset sidecar (still the only persisted ArcRho notes owner), and a confirmed remote update writes the local sidecar note into ResQ method Notes with ResQ-compatible line breaks.
  - An empty note on the confirmed version clears the other side's note; only a sync payload without the notes field (older bridge or unreadable sidecar) leaves notes unchanged.
  - ArcBot method comparisons are unchanged and do not include Method Notes.
- **cape cod**: New Cape Cod method page mirrors the ResQ Generalised Cape Cod editor with Details, Method, Ultimates, Ratios, Notes, and Audit Log tabs.
  - Method tab selects a Latest triangle, Exposure vector, and Prior Ultimate vector (Latest / Ultimates or Pattern mode) and computes every ResQ-verified derived column with a Total row, trend rate fit/auto-fit, decay factor, scaling, decimal places, and per-origin trend factor overrides.
  - Ultimates tab shows the as-if diagnostic ultimates triangle and the Ratios tab plots the six Cape Cod ratio series.
  - Cape Cod opens from the Home launch cards and from Project Instance rows (Add -> Cape Cod on eligible vector rows), with floating-window state, active tab, dirty-close handshake, and CC@ method JSON resolution wired like Bornhuetter Ferguson.
- **cape cod**: New Cape Cod method page replicates the ResQ Generalised Cape Cod method with Details, Method, Ultimates, Ratios, Notes, and Audit Log tabs.
  - Inputs mirror ResQ one-to-one: Latest triangle, Exposure vector, Prior Ultimate vector (Latest/Ultimates or Pattern mode), Trend Rate with Fit and Auto Fit, Decay Factor, Scaling, Decimal Places, Alternative Ultimate Calculation, and per-origin Trend Factor overrides.
  - Every Method-tab column, the fitted trend rate, and the diagnostic Ultimates triangle were validated against the ResQ COM output of an existing Cape Cod method; formulas agree to floating-point precision before ArcRho's canonical six-decimal persistence rounding.
  - The method publishes its ultimate vector with aggregated 3/6/12 variants, participates in dependency refresh (Review Needed propagation), and its output is selectable in Result Selection.
  - ResQ migration imports Cape Cod methods (method type code 3) as CC@ method JSON through the same canonical calculation contract used by the app.
- **dataset**: Open dataset and method windows now alert once when the object is updated by another user or an automation process, with a Refresh Now button to reload the window in place.
  - Dataset Viewer, DFM, Bornhuetter Ferguson, Cape Cod, and Result Selection windows watch the opened object's files with a lightweight background check.
  - Refresh Now reloads the window to the updated values; windows with unsaved changes keep them and explain why the refresh is blocked.
  - Your own saves never trigger the alert, and neither do dependent updates started from your own app: those windows keep their live-preview values until the Engine finishes, then reload the refreshed values automatically.
- **dfm**: The DFM Ratios formula bar has a new paste control that turns an Excel workbook path and range on the clipboard into a linked formula.
  - Paste accepts a bare or '='-prefixed reference, quoted or unquoted, including one embedded in a larger formula, and rewrites it into the canonical form.
  - Clipboard text without a workbook path is reported in the formula-bar tooltip and leaves the cell unchanged.
  - The paste, refresh, and open-workbook controls now use matching stroke SVG icons and the shared ArcRho tooltip instead of native browser tooltips.
- **startup**: Update checks now use GitHub Releases and show a download progress bar.
  - The desktop update checker now looks for a newer installer on the project's GitHub Releases instead of the internal network update feed.
  - Accepting an update downloads the installer over HTTPS to the local machine, showing a live progress bar while it downloads.
  - The downloaded installer is still verified against a published SHA-256 checksum before it is launched.
- **shell**: Home now supports custom groups of shortcut cards that jump straight to the pages you use most.
  - Create a group on Home, then add a card from any open tab, including a Project Instance, dataset, DFM, workflow, or My Workspace folder.
  - Clicking a card follows each page's own rule: a Project Instance card focuses the tab for that project, while a dataset or DFM card opens a new tab.
  - Rename, reorder, move between groups, and remove cards from a right-click or ... menu; General and Automation stay fixed.
  - Custom groups and cards are saved per Windows user and survive Clear Cache & Reload and app restarts.
- **project instance**: Temporary-view generated datasets can now be made permanent from their context menu.
- **dataset**: Dependent updates after a dataset or method save now run on ArcRho Engine, so saves finish in seconds instead of waiting for the whole cascade.
  - The save writes only the saved object and shows an "Updating dependents..." progress status while the Engine refreshes downstream datasets, methods, and the dataset index.
  - Downstream methods are marked Needs Review immediately, and the Project Instance dataset table refreshes when the update job completes.
  - Saving is blocked with a clear message when the ArcRho Engine service is not available; unsaved work stays in the window.
