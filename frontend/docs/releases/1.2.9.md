# Release 1.2.9

Released on 2026-08-09.

## User-Facing Changes

### Improvements
- **dataset**: Deleting a dataset or method from the Project Instance table responds much faster over a network drive.
  - Finding which cached files a dataset owns now reads the folder listing instead of opening every sidecar, and only method files still need their payload.
  - The table redraws from the index the delete already returned instead of re-reading it from the share.
  - Index scans use a wider worker pool, so the remaining rebuild spends less time waiting on network round trips.
- **dataset**: Deleting datasets from the Project Instance table now shows a loading spinner with an elapsed counter until it finishes.
  - The indicator uses the same overlay as the project load, so it follows the current light or dark theme.
  - It clears whether the delete succeeds or fails, and cancelling the confirmation never shows it.
