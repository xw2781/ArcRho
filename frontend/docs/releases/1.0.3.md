# Release 1.0.3

Released on 2026-06-13.

## User-Facing Changes

### Features
- **shell**: Added an ArcBot Ask for Approval mode that reviews proposed DFM edits in the DFM version compare window before saving.
- **scripting**: Added Arcode as a standalone scripting app with its own launch page and code-file tabs.
  - ArcRho scripting launch actions now open Arcode in the desktop app.
  - Arcode uses the same ArcRho backend scripting APIs and app frame styling.
  - Arcode now matches the ArcRho titlebar and ArcBot panel controls.
  - Arcode fills its standalone window without an extra outer gutter.
  - The Arcode launch page now focuses on file actions without the standalone-app intro copy.
  - ArcRho and Arcode can now run side by side against one shared backend service.

### Improvements
- **dataset**: Calculated dataset sidecars now track formula graph links and refresh downstream chains after source or formula changes.
  - Sidecars store direct `Precedents` and `Dependents` from Dataset Types formulas.
  - Dataset and Project Settings show a recalculation report when calculated CSV chains are refreshed.
- **dataset**: Open calculated dataset tabs now refresh when an upstream component save recalculates them.
  - Dataset and DFM output saves broadcast dependent recalculation reports through the shell.
  - Matching open Dataset tabs and Project Instance nested dataset windows reload automatically unless they have unsaved local edits.
- **scripting**: Simplified the Macro window list so it shows macro names while keeping details in the description panel.
- **scripting**: Fixed Macro window splitter resizing and added a splitter context menu for Run, Edit, and Delete actions.
- **arcbot**: ArcBot now treats the active Project Instance nested window as primary app context while noting other visible nested windows.
  - The App Context hover text now shows Project, Segment, Active Tab, Method Type, and visible nested-tab count for Project Instance pages.
- **build**: ArcRho release builds now publish the latest Python API wheel for notebook users.
  - The app build creates a fresh arcrho_api wheel before packaging the app.
  - The wheel is bundled with the app and copied to the shared packages folder as arcrho_api-latest.whl.
  - The Python API can also be published independently from python-api/tools without rebuilding the desktop app.

### Fixes
- **arcbot**: Fixed ArcBot setup so a successful Codex CLI install does not reopen the install prompt when the command path needs a refresh.
- **dfm**: Fixed DFM RPC sync so returned remote JSON and comparison timestamps preserve the ResQ output-vector Modified wall-clock time.
- **dfm**: DFM Results saves now preserve dataset graph sidecar metadata and refresh dependent calculated datasets.
  - DFM output sidecars are saved through the app-server sidecar endpoint instead of a minimal browser-written JSON file.
  - Saving a DFM output vector now reports dependent calculated dataset refreshes in the save status.
