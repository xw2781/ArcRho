# Release 1.2.12

Released on 2026-08-10.

## User-Facing Changes

### Improvements
- **admin control**: Anchored the Folder Access user list below its input with filtering and vertical scrolling.
- **admin control**: Sized the engine and bridge instance limit fields to 60px for a more compact admin control form.
- **admin control**: Simplified Folder Access to one editable user box with C:\Users names as PRCINS principals.
- **admin control**: Polished Folder Access dropdowns and listed every profile folder under C:\Users for selection.
- **admin control**: Added selectable local Windows accounts and common principals to the Folder Access user field.
- **dfm**: Refined dark-mode colors for excluded ratios and selected average formulas in the DFM Ratios tab.
- **app update**: The update prompt now shows a short, plain-text list of user-facing changes instead of the full release notes.
  - Internal notes, fragment sources, and the section headings no longer appear in the dialog.
  - Markdown symbols such as ##, ###, and ** are no longer shown as literal text.
  - Each change shows its one-sentence summary, so the dialog no longer opens tall enough to need its own scrollbar.
  - A release with more than 12 user-facing changes ends with a link to the full release notes.
- **app update**: In-app updates now download the installer to your Downloads folder and delete it after the update is installed.
  - The installer was previously kept under the app's AppData folder on the C drive, where every installed update was left behind for good.
  - A download never overwrites a file already in Downloads; a name in use takes a numbered suffix.
  - The next launch after an update deletes the installer it was installed from, and also clears installers left in the old AppData updates folder.
  - Cancelled downloads and installers that fail checksum verification are removed immediately.

### Fixes
- **runtime**: ArcRho now keeps local preferences isolated when different Windows users run the same packaged build on one PC.
  - A backend can be reused only by ArcRho windows from the same Windows user-data profile.
- **dataset**: Opened method-backed datasets from both Precedents and Dependents in their related method windows.
- **home**: Home card drag tooltips now close when a card opens another page.
- **app update**: App updates now retry a verified installer when Windows briefly blocks it immediately after download.
  - Installing an update could stop with "spawn EBUSY" as soon as the download progress bar completed.
  - ArcRho now closes its own handles on the installer before starting it and retries a blocked launch for several seconds.
  - ArcRho falls back to the Windows shell if direct installer launch remains unavailable.
  - If automatic launch still fails, the error shows the verified installer path so it can be run manually.
