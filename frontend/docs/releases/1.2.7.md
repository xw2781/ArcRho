# Release 1.2.7

Released on 2026-08-09.

## User-Facing Changes

### Improvements
- **dataset**: The Data grid loading preview now matches the shape of the dataset being opened instead of always showing a triangle.
  - Opening a vector dataset previewed a full triangle while it loaded, which then collapsed to a single column once the data arrived.
  - The preview now reads the data format the window was opened with, so a vector shows one column of values under its own column label and a triangle keeps its staircase.
  - The shape comes from information the window already has, so opening a dataset makes no extra request and a vector preview draws fewer cells than before.

### Fixes
- **project instance**: A dataset table reload run from a macro no longer reports a timeout while it is still running, and now says when it had to rebuild the dataset index.
  - The Import ResQ Reserving Class macro allows the reload 30 seconds, but the app gave up after a fixed 10 seconds and reported 'Timed out waiting for Project Instance' even though the table loaded moments later. The app now waits for as long as the caller asked.
  - Reloading the dataset table re-checks the reserving-class folder and rebuilds index.json whenever the folder no longer matches it, which reads every sidecar and method file. Over a network share that is the difference between an instant reload and a slow one.
  - The status bar and the macro's completion dialog now report when a rebuild happened, why, and how long it took, so a slow reload is no longer an unexplained wait.
- **project settings**: Source Data now opens from its cached summary instead of re-reading the whole imported table on every load.
  - The cached table summary is shared by everyone working on a project, but two ArcRho versions used the same cache file name and each rejected the other's copy, so both kept rebuilding it. On a large imported table that turned every Source Data load into a full re-read of the file.
  - The cache file name now carries its format version, so different ArcRho versions keep their own copy and each one loads from cache.
  - Reloading the source table clears every cached summary for the project, as it did before.
