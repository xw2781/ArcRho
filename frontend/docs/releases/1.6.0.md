# Release 1.6.0

Released on 2026-09-13.

## User-Facing Changes

### Features
- **dfm**: The DFM ratio chart window now lists every average formula's value for the column and lets you pick the selected formula there.
  - A compact strip under the ratio plot places each formula's value on one shared axis so the magnitudes can be compared at a glance.
  - The selected formula is highlighted and its value runs across the strip as the same dashed guide the plot draws.
  - Clicking a formula row selects it for the column exactly as clicking its summary cell does, and the chart follows.
  - The chart window can be resized from any edge or corner, and both the plot and the formula list grow with it.
  - The gap between the plot and the formula list is a splitter: a blue line marks it when the pointer is over it, and dragging it opens the list up to show every formula at once without scrolling.
  - The list always keeps ten formulas on screen however short the window is made or wherever the splitter is dropped, and a shorter list keeps all of them.
  - The strip is ruled at round figures counted off from a ratio of 1 whenever the values come close to it, at an interval that suits the range, and with as many lines as the width of the window can label.
  - The formula name column is sized to the longest name rather than a fixed width, and a column whose formulas all sit just above 1 starts on the 1 line at its left edge.
  - The plot's x-axis labels sit just under the axis instead of leaving spare space below them.
- **shell**: Full screen now hides the title bar, the menu bar and the tab bar, and gives the page the whole screen.
  - F11 still switches full screen on and off.
  - Moving the pointer to the top edge of the screen slides the three rows back over the page, and they slide away again once the pointer leaves.
  - An open menu, or a tab being dragged, keeps them in place until it is finished.

### Improvements
- **project instance**: The Dependency Graph now draws what a formula-built dataset is made from and marks it Generated.
  - A dataset the app builds by a formula over other imported datasets used to sit in the diagram as a lone box labelled Imported, with nothing showing where its numbers came from.
  - It is now labelled Generated, with its own colour in the legend, while a dataset filled straight from one source column stays Imported.
  - Its inputs are joined to it by arrows, so clicking an input lights the formula and every method that reads it, and clicking one of those methods lights the formula and its inputs.
  - Those inputs are drawn in the default view instead of waiting for the Show all box, because something now reads them.
- **dfm**: The sync icon has been removed from the DFM tab bar.
  - The tab bar now ends with the tabs themselves, and nothing else about a DFM changes.
- **excel add-in**: A dataset several Excel formulas ask for is now read once per recalculation instead of once per formula.
  - A sheet of single-cell formulas over one triangle used to read that triangle again for every cell; it is now read once and reused for the rest of the pass.
  - A ribbon refresh still picks up an edited dataset, because the reuse is dropped at the start of each pass and again before each block it re-enters.
  - Turning "always refresh" on still makes every formula read its dataset again.
  - The add-in version moves to 2.4.0, which resets each user's saved add-in settings to their defaults on first use.
- **excel add-in**: Excel now gives a new PC its own access to the ArcRho Server the first time it opens, with nobody setting the PC up by hand.
  - The first time the add-in loads on a PC with no ArcRho access, it sets that PC up for the person logged in and says so in the loading window while it does; formulas then work straight away.
  - A PC that already has access, including one where access was deliberately turned off, is left exactly as it is.
  - A PC away from the office tries once when Excel opens and then carries on, so it never pauses again during that session.
- **excel add-in**: Excel formulas now get their figures from the ArcRho Server instead of opening files on the shared drive.
  - A PC that has an ArcRho Server credential asks the server for a triangle, a vector, the period headings or the project settings in one request, and the server answers with the figures.
  - A triangle typed in at one set of periods and asked for at a coarser one is now rolled up on the server and nothing is left behind on the shared drive.
  - When the server cannot answer, the formula shows the server's own explanation instead of saying a file is missing.
  - A PC without a credential still reads from the shared drive exactly as before.
  - The add-in version moves to 2.5.0, which resets each user's saved add-in settings to their defaults on first use.
- **excel add-in**: Excel formulas now read ArcRho data only from the ArcRho Server, never from the shared drive.
  - The add-in no longer opens any project file on the shared drive: it asks the ArcRho Server for a triangle, a vector, the period headings or the project settings, and the server answers with the figures.
  - Nothing is written to the shared drive any more, so no request files and no leftover copies of a rolled-up triangle are created while a workbook calculates.
  - A PC that has not been given ArcRho Server access now sees one short explanation in the cell instead of a missing-file message, telling the user to ask the ArcRho team for access.
  - The Select Datasets window now asks the ArcRho Server for the project's list of dataset types instead of opening the project's own file on the shared drive.
  - The diagnostic command that sent formulas back to the shared drive has been removed.
  - The add-in version moves to 2.6.0, which resets each user's saved add-in settings to their defaults on first use.
- **dataset**: A dataset the app builds from a formula over other datasets now shows what it is made from, and what is made from it.
  - The Details tab lists the formula's inputs on one side and the datasets and methods that read it on the other, the same way a hand-written formula has always been listed.
  - Rebuilding such a dataset now brings those links up to date, so importing source data repairs them instead of keeping whatever they were first written with.
  - An input that has no dataset in the class is left out of a formula-built dataset's inputs, because the app rebuilds it from the source table rather than from those datasets.
- **project instance**: Opening a project for the first time now starts on the first reserving class path instead of an empty page.
  - When the project has no last-used path and no Shortcut item, Project Instance selects the first path of the All Paths tree and expands the tree to show it.
  - The automatic choice skips hidden paths and is not saved as the project's last used path; only a path you pick is remembered.
- **dataset**: A project brought in from ResQ now shows the same formula links the app writes.
  - A dataset the app builds from a formula over other datasets arrives from an import already listing what it is made from and what reads it, instead of arriving with nothing.
  - An input that has no dataset in the class is left out of such a dataset's inputs, matching what the app writes when it rebuilds one.

### Fixes
- **excel add-in**: Excel formulas can now pull a hand-entered triangle at a coarser shape than the one it is stored at.
  - A triangle typed in monthly and shown yearly used to answer "local dataset cache not found" in Excel; it now returns the yearly figures.
  - The rolled-up figures are built on the server from the stored triangle, exactly as the app builds them, and are rebuilt whenever the stored figures change.
  - Hand-entered vectors are not covered: a vector still has to be asked for at the period it is stored at.
- **project instance**: The reserving-class path tree keeps its favorite stars on the right edge when the left panel is narrow.
  - Once any visible level tag no longer fits beside its path label, all level tags hide together instead of being cut mid-word, and return when the panel widens.
  - A long path label runs under its star instead of pushing the star out of view; hovering still shows the full path.
- **source data**: Importing source data for chosen dataset types now also rebuilds the datasets built from them by formula.
  - Choosing one dataset type on the Import Scope step used to rebuild only that type, so a dataset the app builds from a formula over it kept its old values, and everything downstream of that dataset kept them too.
  - The import now works out the whole chain before it starts: the types you chose, the formulas built on them, and the formulas built on those, in every reserving class the import covers. A type with no dataset of its own in between no longer breaks the chain.
  - Methods that read a rebuilt dataset are refreshed in the same run, and a dataset that could not be rebuilt is still reported with nothing downstream of it claimed as refreshed.
  - Saving Data Processing Rules rebuilds the same chain, for the same reason.

## Internal Notes

- **project settings**: One shared rule now decides which dataset types a formula reads, wherever the app reads a formula.
  - A formula that quotes one input and leaves another unquoted counts both everywhere; the Dataset Types tab used to ignore the unquoted ones as soon as any name was quoted.
  - The shared reader also answers which types a formula-built dataset feeds, generated types included, which later steps use to keep those datasets current.
