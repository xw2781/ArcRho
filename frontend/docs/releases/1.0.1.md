# Release 1.0.1

Released on 2026-06-12.

## User-Facing Changes

### Features
- **scripting**: Added a Validate Notes macro that previews corrected DFM adjustment notes before applying them.

### Improvements
- **build**: Updated the ArcRho app version metadata and launch splash version display to 1.0.1.
- **dfm**: Improved DFM User Entry formula references with active source-cell outlines and drag-to-repoint editing.
- **scripting**: Apply Growth Adjustments can apply workbook adjustments to a DFM even when the method has no prior actuary notes.
  - Adjusted User Entry values are stored at six-decimal precision so the displayed fourth decimal stays consistent with the UI.
  - Adjustment note multipliers now use compact values such as 1.02 instead of 1.0200.
- **dataset, dfm**: Manual input triangle caches now load locally and aggregate only from finer cached detail.
  - DFM Input Triangle refresh no longer auto-generates missing input caches; it shows a clear error when the named triangle sidecar or compatible cache is unavailable.
  - Dataset and DFM can derive coarser requested periods from finer manual cumulative caches, while fixed coarse manual caches are not expanded to finer detail.
- **project instance**: Replaced the Add Dataset picker filter Clear All button with an All checkbox that resets the filter.
- **project instance**: Added sorting, filters, and Dataset Type Name search to the Project Instance Add Dataset picker.
- **project instance**: Updated the cached dataset status label to show the number of record(s).
- **project instance**: Replaced the Project Instance dataset table filter Clear All button with an All checkbox that resets the filter.
- **project instance**: Added a Project Instance dataset-table refresh button and removed automatic table refresh after nested saves.
- **project instance**: Matched the project instance tree preferences action to the shared path picker gear icon, spacing, and open-panel highlight behavior.
- **dataset**: Project Instance now exposes the shared reserving-class tree Hidden Paths, Filter, and Preferences controls in its left panel.

### Fixes
- **dataset**: Calculated dataset adds can now resolve saved DFM method dependencies even when their result CSVs are missing.
- **dataset**: Dataset Viewer now shows decoded migrated dataset names and avoids draft-only duplicate-name warnings when opening existing datasets.
- **dfm**: Load manual input triangle caches in DFM by instance name.
  - DFM Data-tab refreshes now treat a cached CSV as valid when the sidecar's project, reserving class, and decoded instance name match, even if the manual dataset type is a broader label such as `Net Loss - ad hoc`.
- **dfm**: DFM Data and Results percent-formatted cells now display with one decimal place.
- **dfm**: Kept separate DFM ratio exclusion clicks from merging into one undo or redo step after a missed mouseup event.
- **dfm**: Fixed DFM RPC sync so returned remote JSON uses the ResQ output-vector Modified timestamp when comparing versions.
- **dfm**: Fixed DFM method saves failing when the desktop host writes JSON files.
- **dfm**: Updated DFM RPC server write-back to sync User Entry average-formula values into ResQ.
- **dfm**: DFM Sync now shows method JSON last-modified timestamps in UTC instead of converting them to local time.
- **dfm**: Fixed DFM JSON save and load paths so Sync uses the configured workspace projects folder.
- **scripting**: Fixed Macro window descriptions so longer macro summaries wrap instead of appearing cut off.
- **project instance**: Improved Add Dataset picker responsiveness when opening the picker and typing in its search box.
- **project instance**: Stopped Project Instance from showing both encoded and decoded rows for the same cached dataset instance.
- **project instance**: Fixed DFM Notes file-link context-menu actions when the DFM is open as a floating Project Instance window, including popped DFM tab surfaces.
- **dataset**: Project Instance now opens its reserving-class tree with the full project path hierarchy even when a saved picker filter exists.
- **dataset**: Project Instance dataset indexes now carry calculated formula text so instance rows can show their formulas reliably.
- **scripting**: Python script files can be dropped into the shell to open in Scripting Console, and clean script tabs no longer repeat-reload after one disk edit.

### Breaking Changes
- **dfm**: DFM CSV caches now use mode-qualified filenames and no longer normalize older length-only cache names.
  - DFM result and input CSV paths now use the same @Origin@Development@cum@dev filename shape as dataset caches.
  - Older @Origin@Development CSV and JSON sidecar names are treated as literal names instead of base dataset aliases.

## Internal Notes

- **project instance**: Split the Project Instance Add Dataset picker into its own frontend module.
