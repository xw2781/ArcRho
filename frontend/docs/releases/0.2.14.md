# Release 0.2.14

Released on 2026-06-01.

## User-Facing Changes

### Features
- **shell**: Added ArcBot, a desktop-only floating AI assistant backed by the local Codex CLI.
  - ArcBot checks local Codex install and sign-in status, offers an explicit first-time CLI install action, keeps the chat input editable during setup, supports moving/resizing the chat panel, adds a View menu option to show or hide the AI bot launcher icon, uses the ArcBot Mini PNG mark clipped by the circular launcher frame, lets the launcher icon be dragged and smoothly snapped to fully visible or halfway tucked positions at app edges, rotates the same image when tucked, keeps tucked edge/corner attachment and the icon-center offset from the nearest corner during window resize, hides the launcher while the chat panel is open, animates chat open/close transitions, shows compact labeled mode controls below a frameless auto-growing input, adds persisted local chat sessions with reopen/switch/new/history/archive/delete controls, shows a context panel with active-tab and estimated context usage details, presents progress as an in-chat work summary card that expands while running and collapses when complete, keeps raw Codex stdout/stderr in a copyable debug drawer, uses the configured Server Connection root path as the Codex project folder context, creates and uses %USERPROFILE%\Documents\ArcRho as the CLI working directory when the configured root is a network path, prefers npm/bundled Codex CLI shims over WindowsApps helper executables, avoids bundled .cmd path splitting by launching the Node entrypoint directly, can request context and the active in-memory method payload from the active DFM tab, lets Codex edit a local row-compact DFM method JSON temp copy, cleans accidental explanatory text around edited JSON before validation, and can apply host-validated JSON edits only inside the configured Server Connection root with a method-history backup, consistent row-compact JSON output, and latest-change revert.
- **dfm**: Added DFM analysis snapshots to saved method JSON and ArcBot context.
  - DFM method saves and ArcBot active DFM context now include rounded 4-decimal input data triangle values, ratio values, average formula value arrays, and the input triangle CSV path inside the canonical grouped method JSON; method restore behavior remains driven by the existing selection fields, analysis arrays trim trailing null cells from each row, excluded ratio rows are clipped to the corresponding ratio-value row shape, average formula values live under the average formulas object, RPC server sync can keep full triangle snapshots empty while carrying only the first User Entry stored-value row, and all 2D arrays are written with one compact child row per JSON line.
- **dfm**: Enable confirmed DFM RPC server write-back.
  - Updating the remote DFM through RPC now asks for an additional confirmation before using RPC server write access.
  - When the local DFM JSON is newer, the comparison window uses a `Confirm` action for the Local card and shows an app-styled RPC server write confirmation before sending the update.
  - Confirmed `SyncDFM` requests include the local DFM JSON path so `arcrho_bridge` can write excluded ratios, selected formulas, and notes back into the RPC server DFM method and return a status JSON.
- **dfm**: Moved DFM object selection into the Details page.
  - Opening a DFM tab now lands directly on Details. The Details Name field has a project/path-scoped selector backed by the reserving class folder's method_index.json, and selecting a name uses the normal local method lookup to load that DFM object.
  - The Details page groups Project, Reserving Class, and Name under Object Path with Output Vector, Input Triangle, and settings under Method Inputs & Settings.
- **settings**: Stored Dataset Viewer and DFM last-used preferences per project and Windows user.
  - Dataset Viewer, DFM, and future pages now share one project-specific last-used Reserving Class value named lastReservingClassPath under projects/<project>/users/<windows-login>/preferences.json, while Dataset Viewer and DFM keep only their page-specific fields in datasetViewer and dfmObject.
  - New standalone DFM tabs now restore the last DFM Details defaults from dfmObject, including the last DFM Name, after the project-user preferences load.
  - Dataset picker preferences, reserving-class tree filter specs/preferences, and hidden reserving-class paths are also stored in the project-user preference file so they copy with project duplication. The old AppData reserving_class_filter_spec.json file is no longer read or written.
- **dfm**: Add a DFM % Developed curve plot.
  - Right-clicking the DFM Ratios selected-summary table now offers `Show Percentage Developed Curve`.
  - The new floating plot window charts the `% Developed` row against the matching Data-tab development-month labels for each ratio column, so `(1) 11-23` plots at month 11 rather than month 23 or column index 1.
  - The first segment starts at month 1 and ends at the first actual point, so monthly values such as months 1-13 are interpolated before a month-14 actual point.
  - Each ratio-column segment has its own curve selector arranged in a horizontally scrollable `Curve Type By Segment` table with `Period` and `Curve Type` rows, defaulting to linear interpolation with smooth, step, exponential, logarithmic, and power choices available per segment.
  - The curve window can optionally load the same Reserving Class path and DFM method name from a prior project and overlay that project's `% Developed` curve; the prior-project input includes the shared project tree picker, and missing or incomplete matches show an error and do not add a line.
- **dfm**: Add a DFM % Developed selected-ratio row.
  - The DFM Ratios selected-summary table now includes a `% Developed` row below `Cumulative`, calculated as `1 / Cumulative` for each development period.
- **dfm**: Add a DFM average formula table plot window.
  - The DFM Ratios summary table right-click menu now includes `Plot Table Data`.
  - The new floating plot window charts each average formula row across the current development-period columns and includes a row legend.
  - The plot toolbar includes a zoom tool: drag over the chart to zoom into an area, or click the chart once to reset to the original view.
  - The current Selected row is plotted as a distinct dashed line, Esc deselects the active plot tool, and the toolbar includes a hand-drag tool that pans the full chart view with pointer-captured dragging.
  - The plot legend now follows the Dataset Viewer chart legend behavior: label rows and checkboxes hide/show lines, Select All controls all lines, and right-clicking a legend row isolates that line.
  - The plot toolbar includes a pencil tool that lets users click an average-formula point to make that formula the selected value for the clicked development period; points on the Selected line are ignored.
- **arcbot**: Added an ArcBot settings popover for model, reasoning effort, token, status, and login details.
- **project-instance**: Added project instance tabs from Project Explorer for browsing reserving-class paths and project dataset types.
  - Project tree rows now reveal a red open-corner View project contents in a new tab icon on hover or keyboard focus, opening a top-level project instance tab titled with the project name.
  - Project instance tabs show a reserving-class path selector, a dataset type table, and floating in-tab dataset windows that reuse the existing Dataset Viewer page with project/path prefilled.
  - Opening a dataset that already has an open or hidden floating window activates or restores the existing window instead of creating a duplicate.
  - New floating dataset windows default to about 80% of the project instance frame and reuse the most recent floating dataset window size for subsequent opens.
  - Floating dataset window titlebars show the full reserving-class path plus dataset name while minimized toolbar tabs use the dataset name.
  - Floating dataset window titlebars include shell-matching minimize, maximize/restore, and close icon buttons.
  - Floating dataset windows inside project instance tabs use rounded frame corners when the shell's Windows 11 frame flag is active.
  - Floating dataset windows inside project instance tabs can be resized from all corners and edges, with the same dotted resize glyph as the main shell on the southeast handle.
  - Floating dataset windows inside project instance tabs can be maximized within the project-instance frame by double-clicking the titlebar, then restored by double-clicking or dragging the titlebar.
  - Floating dataset window titlebar double-clicks are handled before drag capture so maximize and restore reliably trigger.
  - Floating dataset windows inside project instance tabs can be dragged partially off the left, right, and bottom edges while keeping a side grab area and titlebar reachable.
  - Project instance tabs support Ctrl+W to close the active floating dataset window, including while focus is inside the embedded Dataset Viewer or when Electron routes the close-tab shortcut through the parent shell first.
  - Project instance toolbars include a hidden-tab collection area where floating dataset windows dragged by titlebar anywhere above the main layout highlight the dragged window, show a release-to-minimize banner, minimize with a slower dock-style animation into the matching large-radius minimized toolbar tab showing only the dataset name with a styled full-title hover tooltip, and can later be previewed by full window title from the hidden-tabs button with a one-second hover grace period, restored from the matching minimized tab, restored in bulk, closed individually, or closed in bulk from a wider dropdown list.
  - The reserving-class path selector embeds the same lazy picker body used elsewhere in the app, including the Shortcut section, hidden/filter preferences, favorites, user-defined favorite folders, shared icons, and independent scrolling.
  - The project instance path tree uses tighter left and right spacing with a small left inset and removes the two-sided scrollbar gutter so more path text fits in the left panel.
  - Project instance dataset table header right-click now opens a simplified context menu with Group by choices for Data Format and Category plus a placeholder Reset Columns option, rendering compact nested collapsible group headers inside the original table with top-level record counts shown as low-contrast circular badges.
  - Project instance dataset table group headers now have a right-click menu with Collapse all and Expand all actions for nested subgroup headers within the clicked group.
  - Project instance dataset table filter dropdowns now match the Project Settings Dataset Types table behavior: no checked values means unfiltered, checked values narrow results, and selecting all values is treated as unfiltered.
  - Project instance dataset table initial column widths now auto-fit loaded header and cell contents with a 460px startup cap per column, while manual resize can still expand columns farther.
  - Project instance dataset table column resizing now changes only the dragged column and lets the table's total width grow or shrink instead of redistributing width to other columns.
  - Project instance dataset table headers now paint as opaque sticky header layers so scrolled row contents no longer show through the header cells.
  - Project instance dataset table filter buttons now sit closer to the right resize edge of each header cell.
  - Project instance dataset table body cells now wrap long text while clamping visible content to two lines per cell.
  - Project instance dataset table column labels now sort rows by that column when clicked and show an up/down SVG indicator for the active sort order.
  - Project instance dataset table rendering now precomputes row cell values, filter option lists, and active filter selections once per render so grouping, filtering, and sorting respond faster on project instance tabs.
  - Project instance tabs now show one centered Dataset-style loading animation while the reserving-class path tree and dataset table are loading.
  - Project instance tabs initialize the selected reserving-class path from the project's last-used path, falling back to the first Shortcut item when no last-used path is available.
  - Dataset viewer windows keep move and resize tracking smooth over embedded iframe content by adding a temporary drag shield.
  - The project instance toolbar uses a compact height, shows only the selected reserving-class path without a duplicate selected-path strip in the left panel, uses larger selected-path text for readability, and caps the path label width so more minimized tabs can fit on the right.
  - Project instance panel title bars are omitted so the tree and dataset table start directly below the toolbar.
  - The reserving-class panel defaults to 400px, resizes between 200px and 600px, animates collapse/expand, disables grid transitions and throttles width updates during live splitter drag for responsiveness, collapses when dragged to 200px or smaller, and toggles collapse/expand on splitter double-click.
- **dfm**: Reload active DFM pages when local method JSON changes on disk.
  - DFM tabs now watch the active local method JSON file and automatically apply external disk edits when the page is clean, so ArcBot or hand-edited JSON changes show in the GUI without reopening the tab.
