# Release 1.4.1

Released on 2026-09-03.

## User-Facing Changes

### Features
- **berquist sherman**: The Case Reserve Adequacy User Value row is entered like a spreadsheet cell, accepts formulas and Excel links, and lists its links on a new Links tab.
  - Click a User Value cell and type to enter a figure; Enter commits, Escape abandons, Tab moves along the row, and Delete clears the cell back to the grid's default estimator.
  - A cell accepts a number, an arithmetic formula with ROUND, or a pasted Excel cell reference; a pasted range fills the row to the right, one cell per column.
  - The Links tab lists every workbook cell the User Value rows read, refreshes or hard-codes them, and warns when saved values no longer match the workbook.
- **dfm**: Ratios User Entry formulas can round an operand with ROUND(x, digits), and the growth and cutoff adjustment macro uses it so the adjusted factor reconciles with the method notes.
  - ROUND rounds half up on the decimal digits, in the browser and on the server alike, so 2.38625 to four places is 2.3863.
  - Apply Growth and Cutoff Adjustments now writes = ROUND("Simple - 2", 4) * [Accounting Cutoff][-1] * ..., leaving the adjustment vectors unrounded.
  - Generate Notes for Combined Adjustment shows a rounded term at that precision, so the note's multiplication reproduces the User Entry value.
- **macro**: The Macros panel marks any macro the shared library has a newer version of, and the mark loads that version in one click.
  - The amber Update mark appears on the macro's row once the panel has read the shared library, and its tooltip names both versions.
  - Clicking or pressing the mark copies the library version over the local copy and refreshes the list, without opening the Macro Library window.
  - An unreachable library leaves the rows unmarked and never delays or blocks the macro list.

### Improvements
- **project settings**: The Source Data reload button now only re-reads what the page shows, instead of re-importing the source table and rebuilding every generated dataset.
  - Reload refreshes the table summary, the field mapping, the reserving-class types and the period boundaries, and returns in seconds rather than minutes.
  - Re-importing the external source and rebuilding what depends on it stays with Import Data, which is where that work belongs.
- **dataset**: The Data tab now shows Development Length as a greyed-out 0 for a vector dataset instead of an editable length.
  - A vector has one column of values and no development periods, so the control is dimmed and cannot be opened or changed.
  - Hovering it explains why.
  - Triangles keep the Development Length control exactly as before.
- **dataset**: Engine-generated vectors now keep every origin period instead of blanking the rows after the Development End Date.
  - A monthly vector in an August project keeps its full-year input values in the last four rows rather than showing zeros.
  - Triangles still stop at the latest valuation diagonal.
  - A negative row index in a DFM formula or an ArcRho dataset link, such as [Premium][-1], still lands on the valuation period even when later rows of the vector hold values.
