# Arcode Launch Card Icons

High-resolution raster and SVG assets used by the Arcode home launch cards.

- `python.png`: Python logo rendered from Wikimedia Commons `Python-logo-notext.svg`, sourced from python.org.
- `jupyter.png`: Project Jupyter logo rendered from Wikimedia Commons `Jupyter_logo.svg`.
- `text-file.png`: Generic text-file PNG drawn for Arcode.
- `markdown-file.png`: Generic Markdown PNG drawn for Arcode.
- `jupyterlab-text-editor.svg`: Text editor launcher icon decoded from the locally installed JupyterLab 4.0.2 static bundle.
- `jupyterlab-markdown.svg`: Markdown launcher icon decoded from the locally installed JupyterLab 4.0.2 static bundle.
- `jupyterlab-python.svg`: Python launcher icon decoded from the locally installed JupyterLab 4.0.2 static bundle.
- `jupyterlab-terminal.svg`: Terminal launcher icon decoded from the locally installed JupyterLab 4.0.2 static bundle.
- `snowflake.png`: Snowflake logo rendered from Wikimedia Commons `Snowflake_Logo.svg`.
- `sql-server.png`: Generic SQL/database PNG drawn for Arcode when the remote SQL Server PNG source was unavailable during asset setup.

Third-party logos may be subject to trademark guidelines. Use them only to identify the corresponding technology.
