Use

Build a reusable workflow

  1. Create or open a workflow file.
  2. Add one Global Control step.
  3. Set Default Project and Default Path.
  4. Add Dataset and DFM steps.
  5. Organize steps into folders if the workflow is long.
  6. Save the workflow as a .arcwf file.

Details

Behavior to remember

Global Control

  • Only one Global Control step is allowed.
  • Fresh workflows initialize defaults from last project and path preferences.
  • Dataset and DFM steps can bind to defaults.

Sidebar

  • Steps and folders can be reordered.
  • Folders can nest up to three levels.
  • Context menus create folders and manage rows.

Save/load

  • Workflow state persists in .arcwf.
  • Dirty state is sent to the shell.
  • Embedded DFM settings include output vector when present.
