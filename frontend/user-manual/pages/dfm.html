Workflow

How to build or review a DFM

  1. Open a DFM from Project Instance or create one from Add > DFM.
  2. Complete Details: Project, Reserving Class, Name, Output Vector, Input Triangle, lengths, and decimal places.
  3. Use Data to verify the input triangle values and period labels.
  4. Use Ratios to exclude outliers, select formulas, add cell notes, and review charts.
  5. Use Results to review Latest, Reserve, Ultimate, Ratio Basis, Ultimate Ratio, and Total.
  6. Use Notes for support and review comments.
  7. Use Links to review external Excel sources used by Ratios User Entry formulas or break them into current hard-coded values.
  8. Save the method JSON and output vector CSV.

Tools

Controls users should know

Undo and redo

  • Ctrl+Z undoes ratio changes.
  • Ctrl+Y redoes ratio changes.
  • Stacks are per DFM tab and limited.

Ratio chart

  • Drag thresholds to exclude or restore unprotected points.
  • Click Included All Ratios to clear current chart column exclusions.
  • Y-axis labels support custom boundaries.

Average formula plot

  • Right-click summary table and choose Plot Table Data.
  • Use zoom, hand pan, and pencil selection.
  • Toggle Ratios or Percent Developed view.

Percent developed curve

  • Right-click selected-summary table.
  • Show curve segments by period.
  • Add prior project overlay for comparison.

Cell notes

  • Right-click ratio or average formula cells.
  • Add, edit, or clear notes.
  • Notes show yellow corner markers.

User Entry formulas

  • Select a User Entry cell to view or edit its formula.
  • Dataset references combine the dataset and resolved coordinate in one compact pill, such as Accounting Cutoff @ 2026; average-formula references use the same pill style without syntax quotes.
  • Rendered dataset coordinates show their resolved row and column labels instead of numeric positions such as [-1]; editing still shows the original relative formula.
  • Activate a dataset pill to open that dataset in Dataset Viewer.
  • External formulas can include a full workbook path/name, worksheet, and cell or rectangular range address.
  • Multi-cell array formulas and external ranges use a thin blue outer border with a light glow while preserving interior fills.
  • Validation errors appear in a tooltip by the formula bar—normally above it, with a below-bar fallback near the top of the window—without moving the tables, and keep the draft available for correction.
  • Excel checks release the formula bar after a bounded failure.

Sync and review

  • Sync saves first if dirty.
  • Review local vs remote snapshots.
  • Choose local or remote version.

External links

  • Links appears immediately after Notes and derives its rows from Ratios User Entry formulas.
  • Workbook path/name, worksheet, cell address, current Values, and Ratios destination are separate columns; ranges show their first value followed by ....
  • Use Refresh all or Break all with no selection, or click rows first to act only on selected links.
  • Ctrl-click selects separate rows and Shift-click selects a contiguous range.
  • Breaking replaces every related User Entry cell with its current numeric value and marks the method dirty.

Files

DFM saved format

Method:
projects\...\data\PA_%5C_Direct Group_%5C_Collision\methods\DFM@Paid Ultimate.json

Output CSV:
projects\...\data\PA_%5C_Direct Group_%5C_Collision\datasets\Paid Ultimate@12@12@cum@dev.csv

JSON shape:
{
  "json format": "arcrho-dfm-method-by-tab-v1",
  "details tab": {},
  "data tab": {},
  "ratios tab": {},
  "results tab": {},
  "method metadata": {}
}

Notes are stored only in the output dataset sidecar. Links is a live inventory derived from ratios tab.average formulas.inputs; neither is a separate method JSON section. Breaking a link replaces the related inputs with their current numeric values.

Tabs

Details, Results, Notes, and Links behavior

Details

  • Name is the method identity inside the selected project and path.
  • Output Vector uses vector dataset types.
  • Input Triangle uses triangle dataset types.
  • Name selector reads local method index for the selected path.

Data

  • Loads exact input cache when available.
  • Manual/imported inputs stay local-cache-only.
  • Header labels refresh before Data and Ratios render.

Results

  • Shows Latest, Reserve, and Ultimate.
  • Optional Ratio Basis adds Ratio Basis and Ultimate Ratio columns.
  • Total row sums numeric columns and computes total Ultimate Ratio.

Notes

  • Uses the shared notes editor.
  • Tab and Shift+Tab indent text.
  • Path links work even when DFM is nested in Project Instance.

Links

  • Inventories external references in Ratios User Entry inputs.
  • Standalone ranges include all spilled destination cells and show the first current value followed by ....
  • The toolbar refreshes or breaks all rows, or only the rows selected with normal, Ctrl, or Shift clicks.
  • Breaking a source hard-codes every related current value.
