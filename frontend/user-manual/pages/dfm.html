Workflow

How to build or review a DFM

  1. Open a DFM from Project Instance or create one from Add > DFM.
  2. Complete Details: Project, Reserving Class, Name, Output Vector, Input Triangle, lengths, and decimal places.
  3. Use Data to verify the input triangle values and period labels.
  4. Use Ratios to exclude outliers, select formulas, add cell notes, and review charts.
  5. Use Results to review Latest, Reserve, Ultimate, Ratio Basis, Ultimate Ratio, and Total.
  6. Use Notes for support and review comments.
  7. Save the method JSON and output vector CSV.

Tools

Controls users should know

Undo and redo

  • Ctrl+Z undoes ratio changes.
  • Ctrl+Y redoes ratio changes.
  • Stacks are per DFM tab and limited.

Ratio chart

  • Drag thresholds to exclude or restore unprotected points.
  • Click Included All Ratios to clear current chart column exclusions.
  • Y-axis labels support custom boundaries.

Average formula plot

  • Right-click summary table and choose Plot Table Data.
  • Use zoom, hand pan, and pencil selection.
  • Toggle Ratios or Percent Developed view.

Percent developed curve

  • Right-click selected-summary table.
  • Show curve segments by period.
  • Add prior project overlay for comparison.

Cell notes

  • Right-click ratio or average formula cells.
  • Add, edit, or clear notes.
  • Notes show yellow corner markers.

User Entry formulas

  • Select a User Entry cell to view or edit its formula.
  • Validation errors appear in a tooltip by the formula bar—normally above it, with a below-bar fallback near the top of the window—without moving the tables, and keep the draft available for correction.
  • Excel checks release the formula bar after a bounded failure.

Sync and review

  • Sync saves first if dirty.
  • Review local vs remote snapshots.
  • Choose local or remote version.

Tabs

Details, Results, and Notes behavior

Details

  • Name is the method identity inside the selected project and path.
  • Output Vector uses vector dataset types.
  • Input Triangle uses triangle dataset types.
  • Name selector reads local method index for the selected path.

Data

  • Loads exact input cache when available.
  • Manual/imported inputs stay local-cache-only.
  • Header labels refresh before Data and Ratios render.

Results

  • Shows Latest, Reserve, and Ultimate.
  • Optional Ratio Basis adds Ratio Basis and Ultimate Ratio columns.
  • Total row sums numeric columns and computes total Ultimate Ratio.

Notes

  • Uses the shared notes editor.
  • Tab and Shift+Tab indent text.
  • Path links work even when DFM is nested in Project Instance.
