Tabs

What each tab is for

Details

  • Choose Project, Reserving Class, Name, and Dataset Type.
  • Formula shows clickable source chips.
  • Dependents show downstream calculated datasets.

Data

  • Run or load cached dataset values.
  • Copy, paste, type, and delete editable manual cells.
  • Set cumulative, transposed, time mode, lengths, and number format.

Chart

  • Review curves by row or column.
  • Legend controls visibility.
  • Chart redraws after pop-out, dock, and resize.

Notes

  • Add review notes.
  • Use formatting toolbar.
  • File paths become clickable links after editing.

Audit Log

  • Shows newest events first.
  • Records insert, metadata update, values update, and calculated refresh.
  • Sidecar log is capped.

Pop-out tabs

  • Right-click a Dataset tab to float it inside the Dataset page.
  • The live DOM moves, so state is preserved.
  • Close or right-click titlebar docks it again.

Rules

Important dataset rules

Generated datasets

  • ArcRhoTri can create missing generated caches when source inputs resolve.
  • Generated and calculated outputs are read-only in the grid.
  • Refresh can trigger dependent calculated datasets.

Manual input datasets

  • Drafts open on Details with zero-filled placeholder data.
  • Triangle drafts use a triangular mask.
  • Vector drafts use one value column.
  • Duplicate names are blocked in the selected path.

Period lengths

  • Development Length cannot exceed Origin Length.
  • Origin Length must be a valid multiple of Development Length.
  • Saved sidecar lengths load before the triangle renders.

Notes links

  • Path text is plain while editing.
  • After edit, known file paths become underlined links.
  • Right-click links to open, copy, or open Excel read-only.
