Common issues

Fast checks first

Check Settings > Server Connection. Confirm the root contains the expected projects folder. Then use Clear Cache and Reload.

Refresh the selected path index in Project Instance, rerun the Dataset, and check the sidecar Audit Log. If labels changed, clear cache first.

A recorded precedent may be newer than the method output. Open the method, review inputs, then save to regenerate the output and reset status.

Save, Cancel, or confirm discard. Nested Project Instance windows protect their own dirty state before the top-level tab can close.

Use Calculate Worksheet or Calculate Workbook. Confirm project, path, dataset name, and period length match ArcRho cached data.

Confirm ArcRho is running locally. For a non-default URL, set ARCRHO_APP_URL or pass ArcRhoUI(app_url="http://127.0.0.1:28765").
