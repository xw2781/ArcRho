Typical work

Common Arcode tasks

Review JSON

  • Open DFM JSON or sidecars from ArcRho Help menu.
  • Use JSON syntax highlighting.
  • Use Format for valid JSON.

Edit macros

  • Open macros from the Macro panel Edit action.
  • Save changes in Arcode.
  • Refresh the Macro panel before running changed scripts.

Run code

  • Run supported Python files.
  • Review output in the output panel.
  • Dirty tabs prompt before close.

SQL work

  • Snowflake-style files open in Snowflake SQL editor.
  • Connection profiles live under Arcode app data.
  • ArcBot SQL format validation can propose replacements.
