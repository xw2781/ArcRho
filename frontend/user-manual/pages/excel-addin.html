Actions

When to use each ribbon command

CommandUse it when
Connect and LoginA workbook needs a connection or login setup.
Calculate WorksheetRefresh formulas only on the active sheet.
Calculate WorkbookRefresh all ArcRho formulas in the workbook.
Clear FormulasRemove ArcRho formulas during workbook cleanup.
Load Reserving ClassesUse a picker to insert path components.
Select DatasetsPick dataset names with format/category/search filters.
Reset Add-in ReferencesFix broken workbook references after moving or updating the add-in.

Formula rules

Useful formula behavior

Triangle options

  • Cumulative TRUE returns cumulative triangle.
  • Transposed TRUE flips display orientation.
  • Calendar TRUE requests calendar view.
  • Origin and Development Length choose period aggregation.

Workbook refresh

  • Worksheet refresh scans active sheet only.
  • Workbook refresh scans every workbook sheet.
  • Missing datasets can trigger request files and wait for outputs.

Pickers

  • Load Reserving Classes writes path parts into active cells.
  • Select Datasets filters by category and format.
  • Settings stores paths used by the add-in.
