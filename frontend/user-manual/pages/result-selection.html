Chart tab

Compare dataset vectors

Plotted columns

  • Every loaded source dataset vector is plotted.
  • The selected output vector is plotted as the emphasized series.
  • Origin, Weight, Reserve, and ratio columns are not dataset vectors and are excluded.

Column visibility

  • Use the Columns panel on the right to hide or show any vector; the final visible line cannot be hidden by clicking it.
  • Right-click anywhere on an item to isolate it; right-click that sole visible item again to restore all lines.
  • The selected output is explicitly labeled Selected Ultimate, and display choices do not mark the Result Selection dirty or change saved JSON.

Point details

  • Hover a point to see its dataset name.
  • The tooltip also shows the origin period and formatted value.
  • Live Method edits and source previews refresh the chart automatically.

Calculation

How selected ultimate is calculated

Source values

  • Vector sources use vector row values.
  • Triangle sources use latest available diagonal values.
  • Default sources are DFM outputs in the same category.

Weights

  • Positive weight means selected.
  • Zero weight means not selected.
  • Double-click source cells or weight cells to toggle.

Selected Ultimate

  • Uses weighted average by row.
  • Blank when no positive weighted numeric source exists.
  • Custom overrides can replace calculated values.

Ratio Basis

  • Optional basis dataset adds a ratio column.
  • Percent and decimal settings control display.
  • Total ratio is Total Ultimate divided by Total Basis.
