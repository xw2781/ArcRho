Dataset table

Review, filter, group, and open items

Selection

  • Click selects one row.
  • Ctrl-click toggles rows.
  • Shift-click selects a visible range.
  • Enter opens the focused row.

Filters and grouping

  • All columns except Status can filter.
  • No checked values means no filter.
  • Drag headers to the grouping zone.
  • Group chips can be reordered or removed.

Open behavior

  • Normal dataset opens Dataset Viewer.
  • DFM vector opens a DFM window on Ratios.
  • Result Selection vector opens the Method tab.
  • Show as vector opens the saved output as a normal dataset.

Add behavior

  • Add Dataset opens the shared dataset picker.
  • Generated types run ArcRhoTri refresh.
  • Manual types open an editable draft.
  • Add DFM and Add Result Selection open method windows.

State

Status, refresh, and restore details

Status column

  • Green means sidecar status is current.
  • Yellow means a method-backed output has stale precedents.
  • Method Type comes from the selected path index.

Manual refresh

  • Refresh rebuilds the selected path index.json.
  • Table scroll, grouping, filters, and selection are preserved.
  • Nested saves do not auto-refresh the table.

Dependency links

  • Dataset formula chips open dependent datasets.
  • DFM and Result Selection chips open method windows.
  • The source window path is used even if the left path changed.

Restore snapshot

  • Selected path is saved.
  • Nested window kind, title, active tab, dirty flag, hidden flag, and rectangle are saved.
  • Clear Cache and Reload can restore this workspace.
