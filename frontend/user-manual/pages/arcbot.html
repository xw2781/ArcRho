Context

What ArcBot can see

Active tab context

  • Dataset, DFM, scripting, SQL, or Project Instance metadata.
  • Nested Project Instance windows can become the active context.
  • Minimized nested windows are excluded.

Folder permissions

  • Default read access includes configured Server Connection root.
  • User-added folders can be granted.
  • Write access remains scoped to controlled edit flow.

Prompt guide

  • Reads shared prompt from config\arcbot.
  • Team instruction files are Markdown.
  • Prompt Guide opens inside the shell.

Safe edits

How DFM edits are controlled

  1. The host writes active DFM context to a temporary ArcBot workspace file.
  2. ArcBot edits only the temporary copy.
  3. The host validates JSON and strips accidental extra text when possible.
  4. A backup is created before applying the edit.
  5. Ask for Approval shows the DFM comparison dialog before the live tab changes.
  6. The latest ArcBot edit can be reverted when the target file has not changed again.
