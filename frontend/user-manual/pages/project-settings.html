Panes

What each ribbon page does

Projects

  • Create project folders.
  • Rename, duplicate, delete, and organize projects.
  • Open a project as a Project Instance tab.

Source Data

  • Set source table path.
  • Edit First Origin, Last Origin, and Last Evaluation dates.
  • Reload table summary and clear project header caches.

Field Mapping

  • Map fields to Dataset or Reserving Class significance.
  • Assign hierarchy levels.
  • Pick Dataset Type values from filtered suggestions.

Dataset Types

  • Define Name, Source, Formula, Data Format, Category, Calculated, and Generated state.
  • Use header search and filters.
  • Import/export JSON or XLSX templates.

Reserving Class Types

  • Define hierarchy names and levels.
  • Edit Formula and EEX Formula with component trays.
  • Quote names that contain operators.

Audit Log

  • Review settings changes.
  • Confirm project save activity.
  • Use when investigating unexpected project setup changes.
