Panes

What each ribbon page does

Projects

  • Create project folders.
  • Rename, duplicate, delete, and organize projects.
  • Open a project as a Project Instance tab.

Source Data

  • Set source table path.
  • Edit First Origin, Last Origin, and Last Evaluation dates.
  • Reload table summary and clear project header caches.

Field Mapping

  • Map fields to Dataset or Reserving Class significance.
  • Assign hierarchy levels.
  • Pick Dataset Type values from filtered suggestions.

Dataset Types

  • Define Name, Source, Formula, Data Format, Category, Calculated, and Generated state.
  • Use header search and filters.
  • Import/export JSON or XLSX templates.

Reserving Class Types

  • Define hierarchy names and levels.
  • Use Formula terms to include or subtract atomic members.
  • Quote names that contain operators.

Data processing rules

  • Target one mapped dataset type per rule; its displayed name keeps the exact case and punctuation from the Dataset Types table.
  • Build rules as a When / Then sentence: When picks the dataset type and requested coverages, Then keeps or excludes source rows matching one condition list.
  • Choose Keep only or Exclude from the Then action dropdown.
  • Use each When condition's is / is not dropdown to include or exclude the listed requested coverages.
  • Field selectors use the exact names shown in Field Mapping, including capitalization and underscores such as CO_CD.
  • Use the styled dropdown menus with Arrow keys, Home/End, Enter, and Escape; condition-value suggestions open over the editor chrome instead of being clipped by it.
  • Enter condition values as tokens with suggestions narrowed to source combinations that currently occur for the selected dataset type; amber/red tokens are warnings and do not block future values.
  • Leave the name blank to save an auto-generated name.
  • Hover a rule and drag the grip at the left edge of its Enabled cell to reorder; the displayed order is saved to the project JSON file.
  • Use the compact switch in the rules table to enable or disable a rule, and right-click a rule row to edit, duplicate, enable/disable, or delete it.
  • Resize the Enabled, Name, Dataset type, Applies when, and Effect columns as needed.
  • Run Validate all after the source CSV or Field Mapping changes to refresh dataset-aware suggestions and warnings.

Audit Log

  • Review settings changes.
  • Confirm project save activity.
  • Use when investigating unexpected project setup changes.

Migration

Legacy EEX Formula projects

Project Settings ignores the retired EEX Formula column in legacy JSON so it does not block the rest of the app. To preserve those old Earned Exposure adjustments, an administrator should still run tools/migrate_eex_formulas.py in dry-run mode, review the generated rules, then apply the conversion and verify representative results. Legacy XLSX imports remain blocked until converted.
