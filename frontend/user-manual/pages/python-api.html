Install

Install the first-party package

python -m pip install "<ArcRho install folder>\resources\python_packages\arcrho_api-0.1.0-py3-none-any.whl"

# Development build from this repo
python python-api\tools\build_wheel.py --out-dir python-api\dist
python -m pip install python-api\dist\arcrho_api-0.1.0-py3-none-any.whl

Client

Open a project and reserving class

from arcrho_api import ArcRhoClient, get_server_root, set_server_root

set_server_root(r"E:\ArcRho Server")
print(get_server_root())

client = ArcRhoClient()
project = client.project("NJ Annual Production 2026")
rc = project.reserving_class(r"PA\Direct Group\Collision")

print(rc.list_datasets())
print(rc.list_dfm_methods(refresh=True))

DFM scripting

Review and edit a method

dfm = rc.dfm("Paid Ultimate")

dfm.clear()
dfm.exclude_covid_years(years=[2020, 2021])
dfm.exclude_high(dev_period=1, count=1, reason="High ratio reviewed.")
dfm.set_selected_average("Simple - 3")
dfm.set_selected_average_cell_note(1, "Selected after review.", clear_column=True)
dfm.add_notes("Updated by Python API review script.")
dfm.save()

UI automation

Drive active app windows

from arcrho_api import ArcRhoUI

ui = ArcRhoUI()
ui.wait_for_app(timeout_sec=10)

ui.message_box("Starting review.", title="ArcRho Automation")
window = ui.project_instance.open_dataset("Paid Loss")
window.maximize()
print(window.properties.as_dict())
window.restore()

Agent helper

Compact command-line DFM inspection

python -m arcrho_api.agent --file active-method.json inspect --include summary,average-formulas,ratio-triangle --origin 2020
python -m arcrho_api.agent --file active-method.json exclude-ratio --origin 2020 --development 12 --reason "Reviewed outlier"
python -m arcrho_api.agent --file active-method.json select-average --label "Simple - 3" --development all
python -m arcrho_api.agent --file active-method.json validate

Safety

Read-only and explicit writes

Read-only mode

client = ArcRhoClient(read_only=True)
dfm = client.project("NJ Annual Production 2026").reserving_class(r"PA\Direct Group\Collision").dfm("Paid Ultimate")
dfm.add_notes("In memory only")
dfm.save()  # raises ReadOnlyError

Explicit writes

  • DFM mutations stay in memory until save().
  • Dataset generation writes through the app/data-engine file contract.
  • UI automation targets the active running app state.
