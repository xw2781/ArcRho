Daily use

What users do here

Open and switch work

  • Use top tabs for Project Settings, Project Instance, Dataset, DFM, Workflow, Agent Guide, and Arcode.
  • Floating windows stay inside the shell and keep their live state.
  • Right-click tab surfaces in Dataset or DFM to pop a tab into a floating window.

Save and close safely

  • Ctrl+S saves the active Dataset or DFM, including nested windows inside Project Instance.
  • Dirty Dataset, DFM, Workflow, and scripting tabs show dirty state.
  • Close actions ask for confirmation before discarding unsaved work.

Recover state

  • Browsing History records restore-capable pages.
  • Clear Cache and Reload preserves one-shot restore state through the Electron host.
  • Project Instance restore includes selected path and nested Dataset, DFM, and Result Selection windows.

Use context menus

  • Help menu changes when a DFM or Project Instance window is active.
  • Open DFM JSON and sidecar commands launch Arcode.
  • Reveal in File Explorer opens the selected reserving-class data folder.
