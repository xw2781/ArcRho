Exports

What the migration writes

Triangles

  • Writes length and mode scoped CSV files.
  • Writes sidecars with source metadata.
  • Uses shared filename escaping.

Vectors

  • Writes vector CSV files.
  • Writes sidecars.
  • Preserves origin labels when available.

DFM methods

  • Writes grouped ArcRho DFM JSON.
  • Exports output vector data.
  • Imports ratio selections, formulas, notes, and cell notes where available.

Result Selection

  • Writes canonical v2 RS@Name.json.
  • Writes selected ultimate vector CSV.
  • Stores source values, weights, origin labels, and named Ratio Basis values so the method can reopen without rescanning inputs.

Commands

Run migration from command line

python python-api\migration\resq_data_migration.py --export configured
python python-api\migration\resq_data_migration.py --export all
python python-api\migration\resq_data_migration.py --export triangles
python python-api\migration\resq_data_migration.py --export vectors
python python-api\migration\resq_data_migration.py --export dfms --no-cleanup-target

Macro entrypoint

Primary user workflow

The current user-facing runnable import workflow is the macro at Documents\ArcRho\macros\import_from_resq.py. Keep it aligned with python-api\migration\resq_data_migration.py whenever migration behavior changes.

OptionMeaning
--export configuredUses the configured export flags.
--export allExports triangles, vectors, and DFMs.
--cleanup-targetCleans the target reserving-class folder first.
--no-cleanup-targetPreserves existing files before export.

After import

What to check in ArcRho

  1. Open Project Instance for the imported project.
  2. Select the imported reserving-class path.
  3. Refresh the cached dataset table.
  4. Open imported triangles and vectors in Dataset Viewer.
  5. Open imported DFM outputs as DFM methods.
  6. Review imported Result Selection methods from vector rows.
  7. Check sidecar status and method notes before using outputs.
