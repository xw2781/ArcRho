Navigation

Choose what you want to do

01 Set up a project

Create project folders, map source fields, and define dataset and reserving-class types.

 02 Open a project workspace

Select a reserving class, review cached datasets, and open nested work windows.

 03 Review or edit data

Run triangles, inspect charts, add notes, save manual inputs, and check audit logs.

 04 Build a DFM

Review ratios, select averages, save ultimate vectors, sync with ResQ, and add support notes.

 05 Select final results

Blend vectors and triangle latest diagonals into a weighted selected ultimate vector.

 06 Automate with Python

Use the API for scripted DFM review, dataset access, UI automation, and task progress.
